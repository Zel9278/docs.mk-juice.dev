# 이 인스턴스의 운영 방침에 대해서

## Juice Server란?

Juice Server는 Misskey의 비공식 포크인 [misskey-juice](https://github.com/Zel9278/misskey-juice)의 [`juice/main` 브랜치](https://github.com/Zel9278/misskey-juice/tree/juice/main)를 따라가는 공식 인스턴스입니다.

## 테스트 인스턴스로서의 위치

Juice Server는 misskey-juice에서 개발한 새로운 기능이나 수정 사항을 실제 운영 환경에서 검증하기 위해 구축·운영하고 있습니다.

- **승인제 신규 가입은 이 검증 목적을 위해 현재 활성화되어 있습니다.** 누구나 자유롭게 가입할 수 있는 인스턴스가 아니라, 가입 신청 내용을 확인한 후 승인하는 방식입니다.
- misskey-juice의 검증 중인 기능을 먼저 활성화하는 경우가 있어, 예상치 못한 문제가 발생할 수 있습니다.
- 문제를 발견하신 경우, Misskey의 메시지로 관리자([@c30](https://mk-juice.dev/@c30))에게 알려주시면 큰 도움이 됩니다.

## 범용 인스턴스로서의 운영

위의 테스트 목적에 더해, **창작 활동을 하는 분이나 다른 사람과 평범하게 교류하고 싶은 분을 위한 범용 인스턴스로도 운영해 나갈 예정입니다.**

이용하시기 전에 반드시 아래 내용을 읽어주세요.

- [규칙](./service/rules.md)
- [이용약관](./service/tos.md)

## 데이터 취급에 대해서

- 데이터베이스는 정기적으로 자동 백업을 수행하며, 암호화하여 외부 스토리지에 보관하고 있습니다.
- 다만, 테스트 인스턴스라는 특성상 검증 중인 문제 등으로 데이터가 손실될 가능성이 전혀 없다고는 할 수 없습니다. 미리 양해 부탁드립니다.
