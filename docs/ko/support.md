# 후원에 대해서

Juice Server의 서버 운영이나 misskey-juice의 개발을 후원해 주실 분들을 위한 페이지입니다.

현재는 [FanBox](https://c30.fanbox.cc/)만으로 후원을 받고 있습니다. 다른 후원 수단은 아직 없지만, 그래도 후원해 주신다면 관리자는 정말 기쁠 것 같습니다.

무리하지 않는 범위에서 괜찮습니다. 응원해 주고 싶으시다면 아래 FanBox를 잘 부탁드립니다.

## 후원처

- [c30 - FanBox](https://c30.fanbox.cc/)

후원해 주신 금액은 서버 운영비와 misskey-juice 개발에 사용됩니다.
