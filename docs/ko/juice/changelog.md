# 변경 이력

misskey-juice의 JUICE 고유 기능에 관한 주요 변경 이력입니다. 본가 Misskey 유래의 변경 사항은 포함되지 않습니다. 전체 이력은 [GitHub 릴리스 페이지](https://github.com/Zel9278/misskey-juice/releases)를 참고해 주세요.

> [!note]
> 이 페이지는 수동으로 갱신되며, [일본어 변경 이력](../../juice/changelog.md)보다 반영이 늦을 수 있습니다. 최신 정보가 필요하시면 일본어 페이지(또는 위 GitHub 릴리스 페이지)도 함께 확인해 주세요.

## v2026.9.0-juice+3.2

- 이모지 신청・아바타 장식 신청의 신규 알림, 승인식 신규 가입 신청, 문의 접수 알림을 실시간 토스트・배너뿐만 아니라 일반 알림 목록(🔔)에도 남도록 변경. 모더레이터가 아닌 역할 정책 보유자에게도 앱 전체에서 상시 실시간 알림이 도착하도록 함
- [이모지 신청](./emoji-request.md)・아바타 장식 신청을, 심사 대기 중이라면 신청자 본인이 취소할 수 있도록 함
- 웰컴 페이지・「계정 추가」 메뉴의 「초대 코드로 등록」 버튼, 「다른 서버 찾기」 버튼을 각각 관리자 설정에서 숨길 수 있도록 함
- JUICE 브랜드 컬러인 오렌지를 기조로 한 표준 테마 「Juice Orange」(라이트/다크)를 추가하고, 표준 초기 테마로 설정
- [릴레이 타임라인](./relay-timeline.md)에서 각 노트가 어떤 릴레이를 통해 도착했는지 표시하도록 함
- [표시 언어 필터](./post-language.md#타임라인-언어-필터)가 일부 타임라인・실시간 스트리밍에 적용되지 않던 문제를 수정. 언어가 지정되지 않은 게시물의 처리 방식과, 자신의 게시물을 항상 표시할지 여부에 대한 설정도 정비
- 「삭제 후 편집」 폼의 오조작 방지(닫기 전 확인 대화상자)와, 내용이 사라지는 버그를 수정
- 편승 리액션으로 원격 이모지를 사용했을 때 본가 Misskey 등에서 하트로 대체 표시되는 문제를 수정
- 영어・한국어・중국어(간체) 번역을 JUICE 고유 항목에 추가

## v2026.9.0-juice+3.1

- [이모지 정보 메뉴](./reaction-enhancements.md#이모지-정보-메뉴)를 리액션뿐만 아니라 노트 본문・CW・프로필 등에 삽입된 이모지에서도 이용할 수 있도록 함
- [공지사항 리액션 기능](./announcement-reaction.md)에서, 남길 수 있는 리액션 종류 수의 상한을 역할 정책에서 설정 가능하도록 함(기본값 20종)
- 편승 리액션으로 원격 이모지를 사용할 때의 저작권 관련 안내문을, 관리 화면과 앱 내 [About JUICE 페이지](./about-page.md)에도 추가
- 즐겨찾기 데크 컬럼의 표시・실시간 반영 관련 버그 수정
- 작업 큐 위젯의 알림음 설정을, 켜기/끄기 전환과 사운드 선택을 분리하는 방식으로 변경

## v2026.9.0-juice+3.0

본가 Misskey 2026.9.0 추종에 맞춘 대규모 릴리스입니다. 주요 추가 기능:

- [리액션 기능 확장](./reaction-enhancements.md)(편승 리액션, 원격 커스텀 이모지 리액션 해결, 리액션 검색 탭 등)
- [게시물 언어](./post-language.md)
- [노트 검색 강화](./note-search-enhancements.md)
- [문의 양식](./contact-form.md)
- 이모지・아바타 데코레이션 신청에 여러 장 일괄 신청・교체 신청・승인 시 편집 기능 추가
- [사용자 랭킹](./user-ranking.md)의 표시 인원수를 JUICE 설정에서 변경 가능(기본 3명)
- 모더레이션・관리자 알림 확충(이모지 신청・문의 등의 새 접수를 컨트롤 패널에 실시간 표시)
- 시스템 이메일 다국어 지원
- 각종 보안 강화(captcha 적용 범위 확대, 로그인 실패 시 본인 알림, 심사 처리의 배타 제어 등)
- 데크 UI의 컬럼에 "즐겨찾기" 추가
- 시작 로딩 화면에 부팅 로그 표시 및 커스텀 스플래시 텍스트 설정 추가
- 작업 큐 위젯의 알림음을 원하는 사운드로 변경 가능
