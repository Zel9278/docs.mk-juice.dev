# 사용자 랭킹

게시물 수・리액션 수를 기준으로 한 사용자 랭킹입니다.

## 확인 방법

탐색 페이지(`/explore`)의 "사용자 랭킹" 탭에서 각각 상위 3명을 확인할 수 있습니다. 로그인하지 않아도 열람할 수 있습니다.

- **게시물 수 랭킹**: 리노트(인용 없음)를 제외한 게시물 수. 인용 리노트는 게시물 수에 포함됩니다.
- **리액션 수 랭킹**: 자신의 게시물이 받은 리액션 수.

## 집계 기간

집계 기간은 기본적으로 12시간 단위입니다. 기간 경계에서 랭킹이 부자연스럽게 비어 보이지 않도록, 직전 기간의 점수도 반영하여 표시합니다.
