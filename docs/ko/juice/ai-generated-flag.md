# AI 생성 콘텐츠 플래그

게시물이나 드라이브 파일이 AI에 의해 생성된 것임을 나타내는 플래그입니다.

## 사용 방법

노트 작성 화면에서 AI로 생성한 이미지・음성 등을 첨부할 때 "AI 생성" 플래그를 설정할 수 있습니다. 설정하면 첨부한 드라이브 파일에도 자동으로 연동됩니다.

- 플래그가 설정된 노트에는 "AI Generated(AI 생성)" 배지가 표시됩니다.
- 리노트 시에도 플래그 표시가 유지됩니다.
- 게시 후에도 편집을 통해 플래그를 변경할 수 있습니다.

**AI 생성 콘텐츠를 게시하는 경우, 반드시 이 플래그를 설정해 주세요.** 자세한 내용은 [규칙](../service/rules.md)을 참고해 주세요.

## 다른 서버와의 연합

플래그 정보는 Juice Server 고유의 ActivityPub 속성으로 연합 대상 서버에도 전송됩니다. 이를 지원하지 않는 서버에서는 단순히 무시됩니다.

## 뮤트 설정

AI 생성 콘텐츠가 포함된 게시물을 뮤트하는 설정도 사용할 수 있습니다. 또한 드라이브의 "AI 생성물만" 필터로 AI 생성물로 등록된 파일만 필터링할 수도 있습니다.
