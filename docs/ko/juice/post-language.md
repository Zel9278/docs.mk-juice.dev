# 게시물 언어

게시물마다 언어를 명시적으로 지정할 수 있는 기능입니다. Mastodon과 호환되는 형식으로 연합됩니다.

## 게시 시 언어 지정

노트 작성 화면에서 게시물의 언어(BCP 47 언어 태그)를 명시적으로 지정할 수 있습니다. 지정하지 않으면 표시 언어 설정이 기본값으로 사용됩니다.

ActivityPub 연합에는 AS2 표준의 `contentMap`을 사용합니다(Mastodon・Akkoma 호환).

## 타임라인 언어 필터

JUICE 고유 기능 설정에서, 홈・로컬・글로벌 타임라인에 표시할 게시물을 언어로 필터링할 수 있습니다. Mastodon의 "필터링할 언어"를 참고한 기능이지만, 다음과 같은 차이가 있습니다.

- 모든 타임라인에 적용됩니다.
- 리노트도 리노트 원본 노트의 언어로 판정합니다.
- 언어가 지정되지 않은 게시물・자신의 게시물은 설정과 관계없이 항상 표시됩니다.

타임라인 화면의 "…" 메뉴에서도 직접 전환할 수 있습니다.

## 검색에서의 언어 지정

노트 검색・리액션 검색의 고급 검색 옵션에, 게시물의 언어로 좁혀보는 기능이 있습니다.

## 로컬 사용자만 표시

홈 타임라인의 "…" 메뉴에, 로컬 사용자의 게시물만으로 좁혀보는 전환 기능이 있습니다. 팔로우 중인 원격 사용자의 게시물을 일시적으로 숨기고 싶은 경우 이용해 주세요.
