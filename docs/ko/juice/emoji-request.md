# 이모지 신청

일반 사용자가 커스텀 이모지 추가를 신청할 수 있는 기능입니다.

## 신청 방법

이모지 신청 페이지에서 아래 항목을 입력하여 신청합니다.

- 이모지 이미지
- 이름
- 카테고리
- 라이선스

신청은 반려 또는 승인될 때까지 보류 상태로 유지됩니다. 승인되면 바로 커스텀 이모지로 사용할 수 있게 됩니다. 반려된 경우 이유가 통지됩니다. 다시 신청하고 싶은 경우 새로운 신청으로 다시 제출해 주세요.

## 신청 건수 제한

동시에 낼 수 있는 신청(심사 대기) 건수에는 제한이 있습니다(기본 3건). 또한 연속 신청을 방지하기 위한 레이트 리밋도 있습니다.

## 신청 이미지의 취급

신청 시, 심사 완료 후 이미지를 삭제할지 여부를 선택할 수 있습니다. 체크한 경우, 승인・반려 어느 쪽이든 심사 완료 시 드라이브 파일이 삭제됩니다(승인 시에는 이모지 쪽에 이미지가 복사되므로 삭제해도 이모지 자체에는 영향이 없습니다).
