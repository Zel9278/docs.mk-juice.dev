# LaTeX(수식) 표시

노트에 LaTeX 형식의 수식을 작성하면 실제로 렌더링되어 표시되는 기능입니다. 본가 Misskey가 과거에 가지고 있던 기능을 Juice Server에서 복원한 것입니다.

## 작성 방법

MFM의 수식 표기법을 사용합니다.

- 인라인 수식: `\(` 와 `\)` 로 감쌈
- 블록 수식: `\[` 와 `\]` 로 감쌈

## 주의사항

- 수식 내용에 따라 표시에 실패할 수 있지만, 이 경우에도 페이지가 깨지지는 않으며 해당 부분만 표시되지 않습니다.
- 이 기능은 서버 전체 설정으로 비활성화될 수 있습니다. 비활성화된 경우 수식 소스가 그대로 코드로 표시됩니다.
