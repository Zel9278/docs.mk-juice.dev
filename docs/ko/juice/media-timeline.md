# 미디어 타임라인

첨부 파일이 있는 노트만 PixelFed 스타일의 그리드/캐러셀 형태로 모아서 보여주는 전용 타임라인입니다. 관리자가 JUICE 고유 기능 설정에서 활성화한 경우에만 이용할 수 있습니다([JUICE 고유 기능 설정](./settings.md) 참고).

## 표시되는 게시물

- 1개 이상의 파일이 첨부된, 공개 범위가 "공개"인 노트가 대상입니다.
- 여러 장이 첨부된 게시물은 스와이프로 넘길 수 있는 캐러셀 형태로 표시됩니다.

## 인라인 재생

동영상・오디오가 첨부된 게시물은 확대 표시(라이트박스)를 열지 않아도 타임라인에서 바로 재생할 수 있습니다.

- 동영상에는 반복 재생・재생 속도 변경・PIP(화면 속 화면)・확대 표시 등 전용 조작 바가 제공됩니다.
- 오디오에는 라이트박스와 동일한 비주얼라이저(게시자 아바타+파형)와 컨트롤 바가 표시됩니다.
- 음량 설정은 라이트박스와 미디어 타임라인의 인라인 재생 전체에서 공유됩니다(기기 로컬에 저장되므로, 한 번 조정하면 이후 어떤 동영상・오디오를 열어도 같은 음량이 유지됩니다).

## 게시물별 표시 제외

게시물 작성 화면의 "..." 메뉴에서 "미디어 타임라인에 표시하지 않기"를 선택하면 해당 게시물만 미디어 타임라인 대상에서 제외할 수 있습니다. 음식 사진 등 미디어 타임라인에는 노출하고 싶지 않은 게시물이 있을 때 이용해 주세요.

이 설정은 미디어 타임라인에만 적용됩니다. 홈・로컬 등 일반 타임라인이나 프로필의 "파일" 탭, 검색 결과 등 다른 파일 필터링 화면에는 영향을 주지 않습니다.

## 탭 표시・숨김

타임라인 화면 탭 바에 미디어 타임라인 탭을 표시할지 여부는 `/settings/juice`에서 이용자별로 개별 전환할 수 있습니다. 자세한 내용은 [JUICE 고유 기능 설정](./settings.md)을 참고해 주세요.
