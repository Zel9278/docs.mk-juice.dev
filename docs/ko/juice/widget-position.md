# 위젯 표시 위치 설정

데스크톱의 상시 위젯 패널이나 모바일의 위젯 드로어를 화면의 좌우 중 어느 쪽에 표시할지 선택할 수 있는 개인 설정입니다.

## 설정 방법

`/settings/juice`의 설정 화면에서 "왼쪽"・"오른쪽"을 선택할 수 있습니다(기본값은 오른쪽).

- 데스크톱: 상시 위젯 패널의 표시 위치가 전환됩니다.
- 모바일: 위젯 드로어(하단 메뉴의 "앱" 아이콘으로 여는 화면)의 슬라이드인 방향이 전환됩니다.

이는 위젯 표시 전체를 좌우 중 어느 쪽에 표시할지에 대한 설정이며, 개별 위젯을 좌우로 나눠 배치하는 기능이 아닙니다.
