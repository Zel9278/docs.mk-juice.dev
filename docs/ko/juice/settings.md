# JUICE 고유 기능 설정

Juice Server에는 표준 Misskey에는 없는 고유 기능이 여러 가지 있습니다. 이러한 고유 기능에 관한 설정은 컨트롤 패널의 **"JUICE" 항목**에 모여 있습니다.

## 설정 가능한 주요 항목

관리자 계정으로 로그인 후, 컨트롤 패널 → "JUICE"에서 아래와 같은 고유 기능의 활성화・비활성화 및 각종 옵션을 변경할 수 있습니다.

- [승인제 신규 가입](./approval-signup.md)의 활성화・비활성화, 가입 사유 필수/선택・최대 글자 수
- 생성된 지 일정 시간이 지나지 않은 계정으로부터의 팔로우를, 대상의 승인제 팔로우 설정과 무관하게 승인이 필요한 팔로우 요청으로 처리하는 기능의 활성화・비활성화, 대상 기간
- [사용자 랭킹](./user-ranking.md)의 집계 기간・표시 인원수
- [릴레이 타임라인](./relay-timeline.md)의 활성화・비활성화
- [미디어 타임라인](./media-timeline.md)의 활성화・비활성화
- [이모지 신청](./emoji-request.md)・아바타 데코레이션 신청의 활성화・비활성화, 동시 신청 건수 상한
- [LaTeX(수식) 표시](./latex.md)의 활성화・비활성화
- [문의 양식](./contact-form.md)의 활성화・비활성화, 카테고리 관리, 본문 최대 글자 수
- [신고](./abuse-report.md) 카테고리 관리
- 이메일 주소 별칭(Gmail의 점 무시・+태그)을 이용한 다중 계정 가입 차단(기본값은 비활성화. 오탐 위험이 서로 다르므로 점 무시와 +태그는 개별적으로 ON/OFF할 수 있습니다)
- 웰컴 페이지・「계정 추가」 메뉴의 「초대 코드로 등록」 버튼, 「다른 서버 찾기」 버튼의 표시・숨김
- 시작 로딩 화면에 표시할 커스텀 스플래시 텍스트

개인별 설정([위젯 표시 위치](./widget-position.md), 타임라인 탭 바에 표시할 타임라인 선택・순서 변경 등)은 이와 별도로 `/settings/juice`에서 변경합니다.

각 기능의 자세한 내용은 해당 페이지를 참고해 주세요.
