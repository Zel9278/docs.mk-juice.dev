# JUICE 고유 기능 설정

Juice Server에는 표준 Misskey에는 없는 고유 기능이 여러 가지 있습니다. 이러한 고유 기능에 관한 설정은 컨트롤 패널의 **"JUICE" 항목**에 모여 있습니다.

## 설정 가능한 주요 항목

관리자 계정으로 로그인 후, 컨트롤 패널 → "JUICE"에서 아래와 같은 고유 기능의 활성화・비활성화 및 각종 옵션을 변경할 수 있습니다.

- [승인제 신규 가입](./approval-signup.md)의 활성화・비활성화, 가입 사유 필수/선택・최대 글자 수
- [사용자 랭킹](./user-ranking.md)의 집계 기간
- [릴레이 타임라인](./relay-timeline.md)의 활성화・비활성화
- [이모지 신청](./emoji-request.md)의 활성화・비활성화
- [LaTeX(수식) 표시](./latex.md)의 활성화・비활성화

개인별 설정([위젯 표시 위치](./widget-position.md) 등)은 이와 별도로 `/settings/juice`에서 변경합니다.

각 기능의 자세한 내용은 해당 페이지를 참고해 주세요.
