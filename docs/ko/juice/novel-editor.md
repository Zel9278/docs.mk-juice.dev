# 소설 에디터

[소설 플래그・소설 뷰어](./novel.md)용 본문을 쓰기 위한 에디터입니다. 내비게이션 메뉴에서 열 수 있습니다(`/novel-editor`). 다 쓴 본문은 그대로 .txt 파일로 만들어 소설 플래그를 붙여 게시할 수 있습니다.

## 작품과 초안

- 작품마다 제목・본문・목표 글자 수를 가지며, "작품"에서 전환하거나 "새 작품"을 만들 수 있습니다.
- 초안은 **이 브라우저에 자동으로 저장**됩니다. 같은 브라우저의 다른 탭과도 동기화됩니다.
- 저장 위치가 브라우저이므로 다른 기기나 브라우저와는 공유되지 않습니다. 브라우저 데이터를 지우면 초안도 사라지므로, 중요한 작품은 ".txt로 저장"으로 따로 보관해 두세요. 브라우저 저장 용량을 넘어 저장하지 못한 경우에는 화면에 알림이 표시됩니다.

## 쓰기

본문의 표기(루비・방점 등의 주기, 장 제목, 구분, 페이지 나누기, 굵게 등)에는 색이 붙어 구별하기 쉽습니다. 다음 표기는 버튼으로 입력할 수 있습니다.

| 버튼 | 입력되는 것 |
| --- | --- |
| 루비 | 선택한 문자에 루비를 붙입니다(`[[rb:기저 > 읽는 법]]` 형태로 들어갑니다) |
| 방점 | 선택한 문자에 방점(﹅)・흰 깨점 방점(﹆)・동그라미 방점(●)・흰 동그라미 방점(○)을 붙입니다 |
| 장식 | 선택한 문자를 굵게・기울임・취소선으로 합니다 |
| 들여쓰기 | 선택한 행을 지정한 글자 수만큼 한꺼번에 들여씁니다 |
| 장 제목 | 여기서 시작하는 장의 제목(`[chapter:…]`)을 넣습니다 |
| 구분 | 여기서 장을 나눕니다(`---`) |
| 페이지 나누기 | 여기서 페이지를 바꿉니다(`[newpage]`) |
| 대시・말줄임표 | `――`・`……`를 입력합니다 |

각 표기의 자세한 의미는 [소설 플래그・소설 뷰어](./novel.md)를 참고해 주세요.

### 표시 및 입력 설정

- 줄을 바꾸면 문단 첫머리를 들여쓰기
- 괄호 자동으로 닫기
- 쓰고 있는 줄을 화면 가운데에 유지
- 미리보기를 옆에 나란히 표시
- 서체・글자 크기・줄 높이

"집중 모드"로 하면 에디터를 전체 화면으로 표시합니다. "찾기・바꾸기"에서는 대소문자 구분・정규 표현식・단어 단위 검색도 할 수 있습니다.

## 목차와 글자 수

- 목차에는 장별 글자 수가 표시되며, 누르면 그 위치로 이동합니다.
- 글자 수・원고지 환산(400자 원고지, 1행 20자로 문단마다 줄을 바꾼 경우의 매수)・선택 범위의 글자 수가 표시됩니다. 글자 수에는 공백・줄바꿈・루비의 읽는 법・주기 등의 표기가 포함되지 않습니다.
- "목표 글자 수"를 정해 두면 진행 상황이 표시됩니다.

## 미리보기

소설 뷰어와 같은 모습으로 미리 볼 수 있습니다. 넓은 화면에서는 에디터 옆에 나란히, 좁은 화면에서는 별도 창으로 표시됩니다. 쓰는 동안에도 그대로 미리보기에 반영됩니다.

## 게시 전 확인

"게시 전 확인"은 신경 쓰이는 부분을 목록으로 만들어 별도 창에 표시합니다. 항목을 누르면 에디터의 해당 행으로 이동합니다. 쓰는 동안에도 결과가 갱신되며, 게시할 때도 신경 쓰이는 부분이 있으면 알려 줍니다("그대로 게시"로 그대로 게시할 수도 있습니다). 주로 다음과 같은 부분을 지적합니다.

- 루비 붙이는 방법(《》 앞에 한자가 없음, 한자 이외를 포함한 말에 `｜`가 없음, 루비 표기의 오기)
- 닫히지 않은 괄호나, 대응하는 여는 괄호가 없는 닫는 괄호
- 한 행 안에서 닫히지 않은 굵게・취소선・방점 주기, 닫히지 않은 들여쓰기 주기
- 소설 뷰어가 지원하지 않는 주기(`［＃改ページ］`는 지원하지 않으므로 `[newpage]`를 쓰도록 안내합니다)
- 단독 행이 아닌 `[newpage]`, 내용이 없는 장, 첫 번째 장에 `[chapter:…]`가 없는 경우
- 말줄임표・대시를 하나만 사용함, "・・・"를 사용함, ！？ 뒤에 전각 공백이 없음

## 불러오기・저장・게시

- **불러오기**: 기기 또는 드라이브의 .txt 파일을 새 작품으로 엽니다. 문자 인코딩은 자동으로 판정합니다.
- **.txt로 저장**: 본문을 .txt 파일로 저장합니다.
- **게시하기**: 본문을 .txt 파일로 만들어 드라이브에 올리고, 소설 플래그를 붙여 게시 양식에 첨부합니다.
