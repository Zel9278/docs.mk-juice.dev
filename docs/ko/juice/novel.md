# 소설 플래그・소설 뷰어

게시물에 "소설" 플래그를 붙여 전용 소설 뷰어로 읽을 수 있게 하는 기능입니다. 세로쓰기 문고본 스타일 표시와, 루비・방점 등의 [아오조라 문고](https://www.aozora.gr.jp/) 표기, pixiv 소설 표기에도 대응합니다.

## 소설로 게시하기

### 소설 플래그 붙이기

- **게시 양식**: 아래 도구 모음에 있는 책 아이콘(AI 생성 콘텐츠 플래그 버튼 옆)을 눌러 켭니다.
- **게시한 후**: 내 노트의 "…" 메뉴 → "소설로 표시" / "소설 표시 해제"로 나중에 붙이거나 뗄 수 있습니다.
- **드라이브의 .txt 파일**: 드라이브에서 .txt 파일의 메뉴 → "소설로 표시". 플래그가 붙은 파일을 게시물에 첨부하면 게시물에도 자동으로 소설 플래그가 붙습니다(직접 해제할 수도 있습니다).

소설 플래그가 붙은 게시물은 다음과 같이 다뤄집니다.

- 타임라인과 노트 상세 화면에서 이름 옆에 책 배지가 붙습니다. 배지를 누르면 소설 뷰어로 열립니다.
- "…" 메뉴의 "소설로 읽기"에서도 소설 뷰어를 열 수 있습니다.
- 첨부 파일이 없어도 [미디어 타임라인](./media-timeline.md)에 표시됩니다.
- 일반 타임라인(홈・로컬・소셜・글로벌)의 메뉴에 있는 "소설만 표시"로 걸러낼 수 있습니다.

### 본문을 두는 곳

- **짧은 작품**: 노트 본문에 그대로 씁니다.
- **긴 작품**: 본문을 .txt 파일로 만들어 첨부합니다. 노트의 글자 수 제한을 넘는 장편도 읽을 수 있습니다.
  - 문자 인코딩은 UTF-8・Shift_JIS・EUC-JP 모두 괜찮습니다(자동으로 판별합니다).
  - .txt 파일이 첨부되어 있으면 노트 본문이 아니라 .txt 파일의 내용이 소설로 표시됩니다.
  - .txt 파일이 여러 개 첨부된 경우, 드라이브에서 소설 플래그를 붙인 파일이 우선됩니다.

## 본문에 쓸 수 있는 표기

소설 뷰어는 본문을 **쓴 그대로의 문자**로 표시합니다. MFM(링크・멘션・해시태그・커스텀 이모지・`$[…]` 함수・`<center>` 등)은 해석되지 않고 그대로 문자로 표시됩니다. 그 위에, 소설에서 자주 쓰는 다음 표기만 반영됩니다.

### 장과 페이지 나눔

| 표기 | 의미 |
| --- | --- |
| `---`(독립된 행, 하이픈 3개 이상) | 장 구분. 목차에 장으로 나열되며, 가로쓰기에서는 장마다 "이전 장", "목차", "다음 장"이 표시됩니다 |
| `[newpage]`(독립된 행) | 페이지 나눔(pixiv 소설과 같음). 가로쓰기에서는 한 페이지씩 표시하고 "이전 페이지" / "다음 페이지"로 이동하며, 세로쓰기에서는 여기서부터 반드시 다음 페이지가 됩니다 |
| `[chapter:제목]` | 장 제목. 본문에서는 제목으로 표시되고, 목차에도 이 이름으로 나열됩니다(없는 장은 "제N장") |

```text
[chapter:하나　시작]
본문……

---

[chapter:둘　이어서]
본문……

[newpage]

[chapter:셋　다음 페이지의 장]
본문……
```

::: tip
첫 번째 장에도 `[chapter:…]`를 붙여 두면, 목차에 "제1장" 대신 장 이름이 표시됩니다.
:::

### 루비(읽는 법)

| 표기 | 예 |
| --- | --- |
| `｜기저《읽는 법》`(아오조라 문고) | `｜潮待ち便《しおまちびん》` |
| `한자《읽는 법》`(｜ 생략) | `潮見島《しおみじま》` |
| `＊기저《읽는 법》`・`*기저《읽는 법》`・`\|기저《읽는 법》` | `＊御立会《おたちあい》` |
| `[[rb:기저 > 읽는 법]]`(pixiv) | `[[rb:灯台守 > とうだいもり]]` |
| `$[ruby 기저 읽는법]`(MFM) | `$[ruby 真鍮 しんちゅう]` |

::: warning
`｜` 등의 표시를 생략한 경우, 루비가 붙는 것은 《》 **바로 앞에 이어진 한자뿐**입니다(아오조라 문고의 규칙). 예를 들어 `潮待ち便《しおまちびん》`은 "ち"에서 한자가 끊기므로 "便"에만 루비가 붙습니다. 한자 이외의 문자가 포함된 말에 루비를 달 때는 반드시 `｜潮待ち便《しおまちびん》`처럼 시작 위치를 표시해 주세요.
:::

### 방점(아오조라 문고)

| 표기 | 예 |
| --- | --- |
| `［＃「대상」に傍点］` | `潮待ち便［＃「潮待ち便」に傍点］` |
| `［＃傍点］…［＃傍点終わり］` | `［＃傍点］ここだけ［＃傍点終わり］` |

- 대상 문자열은 주기의 **바로 앞**에 두는 것이 아오조라 문고의 정식 표기입니다(바로 뒤에 두어도 반영됩니다).
- `傍点`(검은 깨점) 외에 `白ゴマ傍点`(흰 깨점)・`丸傍点`(검은 동그라미)・`白丸傍点`(흰 동그라미)도 쓸 수 있습니다.
- 세로쓰기에서는 글자 오른쪽, 가로쓰기에서는 위쪽에 붙습니다.

### 들여쓰기(아오조라 문고)

```text
［＃ここから2字下げ］
들여쓰기할 행
들여쓰기할 행
［＃ここで字下げ終わり］
```

숫자만큼 블록 안 각 행의 맨 앞에 전각 공백이 들어갑니다.

### 문자 장식

| 표기 | 표시 |
| --- | --- |
| `**굵게**` | **굵게** |
| `*기울임*` | *기울임* |
| `~~취소선~~` | ~~취소선~~ |

- 중첩할 수 있습니다(예: `**굵게 안의 ~~취소선~~**`). 장식 안에 루비를 넣어도 괜찮습니다.
- **한 행 안에서 닫혀 있을 때만** 반영됩니다. 줄바꿈을 넘으면 기호 그대로 표시됩니다.
- `* 주`처럼 기호 바로 뒤(또는 앞)가 공백이면 장식이 아닌 단순한 기호로 취급됩니다.

### 그 밖의 pixiv 소설 표기

| 표기 | 표시 |
| --- | --- |
| `[[jumpuri:표시 이름 > URL]]` | 표시 이름의 문자만(링크는 걸리지 않습니다) |
| `[jump:N]` | 표시되지 않습니다 |
| `[pixivimage:…]` | 표시되지 않습니다 |

### 아오조라 문고 형식의 텍스트

- 맨 앞의 "【テキスト中に現れる記号について】" 범례 블록(괘선으로 둘러싸인 부분)은 자동으로 제거됩니다.
- 여기에 나열한 것 이외의 `［＃…］` 주기(미지원)는 주기째 표시에서 사라집니다.

독자가 표시 설정에서 "아오조라 문고 표기 해석"을 끈 경우, 《》 루비・방점・들여쓰기 주기는 해석되지 않고 그대로 문자로 표시됩니다(기본값은 켜짐).

### 자동 들여쓰기

독자의 표시 설정 "문단 들여쓰기"가 켜져 있으면(기본값), 행 맨 앞에 공백이 없는 행에는 자동으로 전각 공백 1칸만큼 들여쓰기가 들어갑니다. 다음 문자로 시작하는 행은 들여쓰기되지 않습니다.

- 이미 공백(전각・반각)으로 시작하는 행
- 여는 괄호: `「 『 （ ( 〔 ［ [ ｛ { 〈 《 【 〘 〖 ｢ “ ‘`
- 기호: `・ ･ ― — ﹅ ﹆ ● ○ ◎ ◯ ◆ ◇ ■ □ ★ ☆ ※ 、 。 ，`

대화문(「」)이나 장면 전환 기호(◆・＊・●○ 등)의 행이 멋대로 들여쓰기되지 않도록 하기 위함입니다. 또한 루비 표기 `[[rb:…]]`로 시작하는 행은 일반 문장 행으로 들여쓰기됩니다.

### 세로쓰기에서의 표시

- 영문자・숫자는 한 글자씩 세워서 세로로 나열됩니다.
- `…` `‥` `―` `—`나 반각 `( ) [ ] { } < > - ~ =` 등은 세로쓰기용으로 90도 돌려서 표시됩니다.
- 루비가 페이지 경계에 걸리는 경우, 잘리지 않도록 그 앞에서 페이지가 나뉩니다(그래서 페이지마다 폭이 조금 달라질 수 있습니다).

### 게시 전 체크리스트

- 소설 플래그를 붙였다(또는 소설 플래그가 붙은 .txt 파일을 첨부했다)
- 한자 이외의 문자가 포함된 말의 루비는 `｜`로 시작 위치를 표시했다
- 목차에 장 이름을 표시하고 싶다면 첫 번째 장에도 `[chapter:…]`를 붙였다
- 굵게 등의 장식은 한 행 안에서 닫혀 있다
- 장편은 .txt 파일로 첨부했다

## 소설 뷰어로 읽기

- **가로쓰기/세로쓰기**: 전환할 수 있습니다. 세로쓰기는 문고본처럼 오른쪽에서 왼쪽으로 페이지를 넘기는 표시이며, 화면이 충분히 넓으면 펼침면(2페이지) 표시가 됩니다.
- **페이지 넘기기**(세로쓰기): 페이지 아래의 버튼 외에도 스와이프(오른쪽으로 밀면 다음 페이지)나 키보드의 ←(다음 페이지) / →(이전 페이지)로 넘길 수 있습니다.
- **전체 화면으로 읽기**: 본문만 화면 가득 표시합니다. 전체 화면 상태에서도 목차・표시 설정・가로쓰기/세로쓰기 전환을 할 수 있습니다.
- **표시 설정**: 글자 크기, 서체(기본・명조체・고딕체), 배경(자동・흰색・세피아・검정・커스텀), 문단 들여쓰기, 아오조라 문고 표기 해석을 변경할 수 있습니다. 설정은 기기별로 저장됩니다.
- **책갈피**: 세로쓰기로 읽던 페이지를 기억해 두었다가, 다음에 열 때 그곳부터 이어서 읽습니다(기기별, 최근 50작품까지).
- **글자 수와 읽는 시간의 기준**: 작가 이름 아래에 표시됩니다. 공백・줄바꿈・루비의 읽는 법은 세지 않으며, 1분당 약 500자로 계산합니다.
- 창 크기를 바꿔도 읽던 위치를 유지한 채 페이지가 다시 나뉩니다.

## 다른 서버에서의 표시

소설 플래그는 Juice Server 고유의 ActivityPub 속성으로 연합 대상에도 전송됩니다. JUICE끼리는 소설로 연합하며, 대응하지 않는 서버에서는 단순히 무시됩니다.

- 관리자가 "소설 게시물 CW 대체"를 켠 경우(제어판의 JUICE 설정, 기본값은 비활성), JUICE 이외의 서버에서는 "소설"이라고 적힌 CW가 붙은 상태로 표시됩니다. 구조는 [AI 생성 콘텐츠 플래그](./ai-generated-flag.md)의 CW 폴백과 같으며, 둘 다 해당하는 게시물에서는 AI 생성 쪽이 우선됩니다.
- JUICE 이외의 서버에서는 본문이 일반 노트로 표시되므로, `［＃…］`나 `[newpage]` 등의 표기는 그대로 문자로 보입니다.
