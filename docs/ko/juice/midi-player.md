# MIDI 플레이어

노트에 첨부된 MIDI 파일(.mid/.midi)을 재생할 수 있는 경량 내장 플레이어입니다. 외부 사운드폰트 등을 사용하지 않고, Web Audio API의 오실레이터 합성만으로 동작합니다.

## 특징

- GM(General MIDI) 음색 패밀리별 합성 레시피를 지원하여, 악기마다 다른 음색으로 재생됩니다.
- 컨트롤 체인지・피치 벤드도 지원합니다.
- 128건반 키보드 비주얼라이저로, 어떤 음이 울리고 있는지 트랙별로 색을 구분해 표시합니다.
- 피아노 롤 비주얼라이저(세로 스크롤)도 갖추고 있으며, tick(박자 내부 단위) 기준으로 재생 위치를 표시하므로 템포가 바뀌는 곡에서도 어긋나기 어렵습니다. 활성화 여부・롤 속도・최대 동시 발음 수는 설정의 "JUICE" 페이지와 플레이어 내 메뉴 어느 쪽에서도 변경할 수 있습니다.
- 음량 조절・탐색 바를 갖추고 있습니다.
- BPM과 동시 발음 수(재생 중인 노트 수)를 실시간으로 표시합니다.
- AudioWorklet 기반 피크 리미터로 음이 깨지는 것을 방지합니다.
- Media Session API를 지원하여, 스마트폰 잠금 화면이나 알림 영역에서도 재생・일시정지 등을 조작할 수 있습니다.
- 확대 표시는 이미지・동영상과 동일한 라이트박스로 통합되어 있으며, 확대 시에도 인라인 표시와 동일한 재생 상태(재생 중인지・재생 위치・음량)를 그대로 이어받습니다. 라이트박스의 "…" 메뉴에서 비주얼라이저 설정도 변경할 수 있습니다.

::: info 참고
- iPhone/iPad에서는 기기의 무음 스위치가 켜져 있으면 소리가 나지 않는 알려진 동작이 있습니다. 해당 환경에서는 경고가 표시됩니다.
:::

## 첨부 가능한 파일 크기 상한

블랙 MIDI 등 노트 이벤트 수가 극단적으로 많은 파일을 분석・재생하면 브라우저가 멈출 수 있으므로, 재생을 허용하는 최대 파일 크기가 설정되어 있습니다(기본 500KB). 상한은 관리자가 컨트롤 패널의 JUICE 설정에서 변경할 수 있습니다. 상한을 초과하는 파일은 플레이어가 아닌 일반 첨부 파일로 처리됩니다.
