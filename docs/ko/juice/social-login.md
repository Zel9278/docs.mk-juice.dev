# 연동 로그인

Discord・Google・GitHub・GitLab・Microsoft 계정과 연동하여, 해당 계정으로 로그인할 수 있게 해주는 기능입니다.

## 연동 설정

설정의 "JUICE" 페이지("계정" 카테고리)에서, 각 서비스 계정을 연동・해제할 수 있습니다. 연동하는 것과 로그인 수단으로 사용하는 것은 별도의 전환 항목입니다.

로그인 수단으로 활성화한 경우, 로그인 화면에 해당 프로바이더의 버튼이 표시되며, 그곳에서 연동된 계정으로 로그인할 수 있게 됩니다.

## 안전을 위한 제약

연동 로그인을 로그인 수단으로 사용하려면, 다음 두 조건을 모두 충족해야 합니다.

- **본인의 Misskey 계정에서 2단계 인증(2FA)이 활성화되어 있을 것**
- **로그인 수단으로 사용하는 것을 개별적으로 옵트인했을 것**(연동만으로는 자동으로 로그인 수단이 되지 않습니다)

이는 연동된 계정(예: Google)이 탈취당한 것만으로 Misskey 계정까지 침입당하는 것을 막기 위한 제약입니다. 본가 Misskey가 과거 유사한 기능을 폐지한 이유에 대한 대책으로, 서버 측에서 강제됩니다.

## 지원 프로바이더

- Discord
- Google
- GitHub
- GitLab
- Microsoft

각 프로바이더는 관리자가 컨트롤 패널의 JUICE 설정에서 활성화한 것만 이용할 수 있습니다.
