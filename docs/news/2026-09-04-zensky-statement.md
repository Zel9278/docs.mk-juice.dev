# ZenSky Project及び『Misskey.Tokyo』様への見解表明

2026年9月4日

私は『[Misskey Juice(JUICE)](https://github.com/Zel9278/misskey-juice)』を開発している**ced([@c30](https://mk-juice.dev/@c30))**と申します。

この度は、ZenSky Project様が提供ならびに運営されている『Misskey.Tokyo』インスタンスについての「[Misskey.Tokyo と Misskey-juice の紛争に関する弊団体の立場と声明](https://s-zensky.com/press-1.html)」の発表に伴い、私としていくつかの項目に分けて**個人的見解**を自分なりにまとめましたので、以下の内容を明記させていただきます。

## 1. まずはじめに

私が開発している『Misskey Juice(JUICE)』は、当初『[Misskey.art](https://misskey.art)』(以下、Artとする)にて「お知らせに対するリアクションをできる機能」を実装し、Artユーザーの皆さまに対してご提供いたしました。

こちらの機能に対し、Artユーザーの皆さまからはとても反応が良かったため、私自身「このような、独自機能があったらいいな〜」をテーマとして、『Misskey.art』から「お知らせに対するリアクションをできる機能」を引き継ぐ形で『Misskey Juice(JUICE)』という名前で新たな計画を立案し、個人的に開発を開始いたしました。

## 2. 『Misskey Juice(JUICE)』、『Juice Server』がフォーク・オープンされた経緯について

上記でも説明させていただきましたが、『Misskey Juice(JUICE)』は「こういう独自機能があったら良いな」をメインテーマとして開発を行っており、日々新たなアイデアを取り入れています。

2026年08月23日、[Askey](https://misskey.tokyo/@askey)氏から「Misskey.Tokyoを運営しませんか?」というご相談をいただいた際にも、私の方で検討中だった「既にArtに実装されている機能に対して、独自のフォークとして新たに開発できないか?」という発想を基に、Askey氏のご相談に対して承諾をする形で、お話を進めさせていただきました。

しかし、09月03日に公開されたZenSky Project [プレスリリース No.1](https://s-zensky.com/press-1.html)では、以下のような掲載(原文ママ)がなされています。

> 最初に、Misskey-juice の開発者である c30 氏から、およそ次のような提案を受けました。Misskey-juice を開発しているので、Misskey.Tokyo の半公式サーバーとして導入してほしい。その代わり、Misskey.Tokyo がほしい機能を聞く、という内容でした。

現時点でも『Misskey.Tokyo』は、『Misskey Juice(JUICE)』の実装並びにユーザーの皆さまへの提供は一切行われておらず、その上、最初のご相談とはまったく異なる主張、『Misskey Juice(JUICE)』の私的利用を示唆する内容が認められます。

このような事態を招いた最大の要因として、

- 双方の認識のズレ(私とAskey氏)
- その後のやり取りにおける確認・伝達不足

などが挙げられ、結果として**適切な対話**や**十分な相互理解**が図られぬまま、大きな食い違いが生じることとなりました。

今後は、そのような事態を招かないように、ユーザーの皆さまとのコミュニケーションをより一層大切にし、『Misskey Juice(JUICE)』の開発に鋭意努力いたします。

## 3. 『Juice Server』をメインとした、今後『Misskey Juice(JUICE)』を利用したいユーザーの皆さまへ

現在『Misskey Juice(JUICE)』は開発段階にあり、自分自身の実装したい機能の先行テストや不具合・バグの修正、デバッグを目的とした**私自身が運用しているインスタンス『Juice Server』**を、**公式インスタンス**として運用しております。

当インスタンスの運用方針として、私自身が想定していない不具合・バグや、検証中の機能を先行して有効にしており、検証目的の面が多く、そのため、今後のアップデートにて様々な機能を追加・修正した上で、**安定したバージョン**の**『Misskey Juice(JUICE)』**をユーザーの皆さまへ提供させていただきます。

詳しくは[このインスタンスの運用方針について](../about-juice-server.md)をご確認ください。
