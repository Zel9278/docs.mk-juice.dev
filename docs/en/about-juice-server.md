# About this instance's operating policy

## What is Juice Server?

Juice Server is the official instance that tracks the [`juice/main` branch](https://github.com/Zel9278/misskey-juice/tree/juice/main) of [misskey-juice](https://github.com/Zel9278/misskey-juice), an unofficial fork of Misskey.

## As a testing instance

Juice Server is built and operated to verify new features and fixes developed in misskey-juice in a real production environment.

- **Approval-based signup is currently enabled for this testing purpose.** This is not an instance anyone can join freely; registration applications are reviewed and approved.
- Features from misskey-juice that are still under verification may be enabled ahead of time, and unexpected issues may occur.
- If you find a bug, please let the admin ([@c30](https://mk-juice.dev/@c30)) know via a Misskey message — it would be a great help.

## As a general-purpose instance

In addition to the testing purpose above, **we also plan to run this instance as a general-purpose instance for people who create things, or who simply want to interact with others.**

Before using the service, please make sure to read the following:

- [Rules](./service/rules.md)
- [Terms of Service](./service/tos.md)

## About data handling

- The database is backed up automatically on a regular basis, encrypted, and stored on external storage.
- However, as this is a testing instance, there is no guarantee that data will never be lost due to issues under verification. Please keep this in mind.

## Contact

For questions, requests, or bug reports, please contact the admin ([@c30](https://mk-juice.dev/@c30)) via a Misskey message.
