# Announcement reactions

A feature that lets you react to admin-created "announcements", the same way you would react to a note.

## How to use it

- You can react with both custom emoji and Unicode emoji (only local custom emoji are supported; remote custom emoji cannot be used).
- You can add multiple different kinds of reactions to a single announcement.
- You can see the list of users who reacted to an announcement.

This can be used together with [announcement polls](./announcement-poll.md) as a way to respond to announcements.
