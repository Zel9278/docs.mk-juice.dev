# Announcement polls

A feature that lets an admin attach a poll to an "announcement" they create.

## How to use it

If an announcement has a poll set, you can vote directly from the announcement display screen. The choices, whether multiple selection is allowed, and the deadline are set by the admin for each announcement.

- Once you vote, you can check what you voted for afterwards.
- Choices cannot be edited after the poll is created.
- Polls cannot be attached to announcements addressed to a specific individual user.
