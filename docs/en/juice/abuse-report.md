# Abuse reports

A feature for reporting users, notes, and chat messages.

## How to report

- Choosing "Report" from a user's "..." menu opens a report form for that user.
- You can also report from a note's or chat message's menu, in which case the target note/message is automatically attached to the report.
- When reporting, you can choose a category (spam, harassment, impersonation, etc.). Categories can be added, edited, and reordered from the JUICE settings in the control panel.

## Preview of the reported content

When a note or chat message is reported, moderators can preview its content on the report detail page in the control panel. For chat direct messages, this is the first-ever way for staff to see the content of a message — and only when it has been reported (chat content isn't otherwise viewable from the control panel).

## Handling on the moderation side

- The report list in the control panel can be filtered by category.
- There's a quick-access entry in the "Tools" menu and a dedicated screen (`/abuses-manager`) for managing reports, so you can review and act on them without going through the full control panel.

## Block then suspend

When an admin or moderator suspends a user, there's an option to first block that user from their own account before suspending them — so they can immediately cut off any retaliatory contact (mentions, follows, etc.) aimed at the person who handled the report. This is available both from the user detail page in the control panel and from the user menu.
