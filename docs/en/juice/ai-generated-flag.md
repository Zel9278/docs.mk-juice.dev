# AI-generated content flag

A flag that indicates a post or drive file was generated by AI.

## How to use it

On the note composer, you can set an "AI-generated" flag when attaching AI-generated images, audio, etc. Setting it also automatically applies to any attached drive files.

- Notes with this flag set display an "AI Generated" badge.
- The flag display is preserved when renoted.
- You can also change the flag after posting, via editing.

**When posting AI-generated content, please always set this flag.** See the [Rules](../service/rules.md) for details.

## Federation with other servers

This flag information is sent to federated servers as a Juice Server-specific ActivityPub property. Servers that don't support it will simply ignore it.

## Mute settings

You can also enable a setting to mute posts with the AI-generated flag. You can also narrow down Drive to only files registered as AI-generated, using the "AI-generated only" filter.
