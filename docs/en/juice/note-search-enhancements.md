# Note search enhancements

The note search screen has advanced search options that let you filter by:

- AND/OR toggle for keywords
- Excluded words
- Whether there are attachments
- Whether CW (content warning) is set
- Whether it's a reply
- Whether it has a poll
- Visibility
- Post language (see [Post language](./post-language.md) for details)

These options are also available in [reaction search](./reaction-enhancements.md#reaction-search).
