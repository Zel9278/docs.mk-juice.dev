# 自訂表情符號・頭像裝飾指南

申請自訂表情符號或頭像裝飾時,請遵守以下指南。請同時參閱[規則](./rules.md)・[服務條款](./tos.md)。

## 共同注意事項

- 如果使用需要標註來源的素材(例如免費素材網站要求必須標示出處),請在「授權」欄中準確填寫出處、作者名及授權類型。如果是自己製作的內容,或素材本身無需標註,則不必勉強填寫。
- 未經授權使用真實企業、團體標誌或商標的申請將被駁回。
- 包含 NSFW、暴力性或歧視性內容的圖片不得申請。適用與[規則](./rules.md)相同的標準。
- 用於重現違反公序良俗的表現等超出預期用途的申請,同樣屬於駁回對象。
- 如果判斷上有疑慮,審核時可能會另外與您確認。不必想得太複雜,歡迎輕鬆申請。

## 自訂表情符號

- 請使名稱・分類易於理解,避免與其他表情符號混淆。
- 申請將保持待審核狀態,直至被核准或駁回。若被駁回,將通知駁回理由。如需再次申請,請以新申請的形式重新提交。
- 詳細申請方法請參閱[表情符號申請](../juice/emoji-request.md)。

## 頭像裝飾

- 使用與自訂表情符號相同的申請機制,需輸入圖片・名稱・分類・授權進行申請。
- 由於該裝飾會疊加顯示在個人頭像上,請設計為透明背景等適合疊加在頭像上的樣式。

## 關於審核

申請的核准・駁回由管理員或經角色授權審核權限的使用者執行。不符合上述指南的申請可能會被駁回。
