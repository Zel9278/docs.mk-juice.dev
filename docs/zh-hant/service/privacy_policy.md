# 隱私政策

## 關於本實例的隱私保護

c30(ced)(以下簡稱「我方」)營運及管理的分散式微網誌 SNS 服務「Juice Server」(以下簡稱「本服務」)就其隱私資訊的處理方式,制定如下隱私政策(以下簡稱「本政策」)。

## 本服務蒐集的個人資料

### 第一條(隱私資訊的定義)

1. 隱私資訊中的「個人資料」指個人資料保護法所規定的「個人資料」,即關於在世個人的資訊,包含出生日期、住址、電話號碼或其他可識別特定個人的記述等資訊。
2. 隱私資訊中的「歷史資訊及特徵資訊」指上述「個人資料」以外的資訊,包括使用者瀏覽的網頁、搜尋的關鍵字、使用日期時間、使用方法、使用環境、年齡、使用者 IP 位址、Cookie 資訊、位置資訊、終端設備識別資訊等。

### 第二條(隱私資訊的蒐集方法)

1. 本服務在使用者進行使用登記時,可能會詢問電子郵件地址等個人資料。
2. 除上述內容外,在確認是否符合本服務服務條款規定的年齡要求時,可能會詢問出生日期等額外的個人資料。
3. 本服務會在使用者使用、瀏覽本服務時,蒐集使用者的歷史資訊及特徵資訊(透過智慧型手機等行動裝置使用時,也包括該裝置的通訊狀態、使用時的各項設定資訊等)。

### 第三條(蒐集及使用個人資料的目的)

本服務蒐集及使用個人資料的目的如下:

1. 為使使用者能夠查看或修改自己的註冊資訊、查看使用情況,而顯示註冊資訊、所使用服務等相關資訊的目的
2. 為進行使用者身分確認,而使用電子郵件地址等聯絡方式資訊的目的
3. 為向使用者告知或聯絡有關本服務的事項,而使用電子郵件地址的目的
4. 為使使用者能夠便捷地輸入資料,依使用者的指示將本服務中註冊的資訊轉送等操作至其他伺服器的目的
5. 為回應使用者的詢問,而使用詢問內容、本服務向使用者提供服務所需的資訊、使用者的服務使用情況、聯絡方式資訊等的目的
6. 附隨於上述使用目的的目的

### 第四條(向第三方提供個人資料)

1. 除以下情況外,本服務不會在未事先取得使用者同意的情況下向第三方提供個人資料。\
   但個人資料保護法及其他法令所允許的情況,或作為使用者公開資訊註冊的出生日期,不在此限。
   1. 基於法令規定的情況
   2. 為保護人的生命、身體或財產而有必要,且難以取得本人同意的情況
   3. 為提升公共衛生或促進兒童健全成長而特別有必要,且難以取得本人同意的情況
   4. 國家機關、地方公共團體或受其委託的第三方機構為執行法令所規定事務需要協助的情況下,若取得本人同意可能妨礙該事務執行的情況
   5. 事先已告知或公布以下內容的情況:
      1. 使用目的中包含向第三方提供
      2. 向第三方提供的資料項目
      3. 向第三方提供的手段或方法
2. 儘管有上述規定,以下情況不視為第三方:
   1. 包括版主在內的本服務營運成員
   2. 在實現本服務使用目的所需的範圍內,委託個人資料處理的部分或全部的情況
   3. 因合併或其他事由導致事業繼承而提供個人資料的情況
   4. 與特定對象共同使用個人資料的情況下,已事先將該情況及共同使用的個人資料項目、共同使用者的範圍、共同使用者使用個人資料的目的以及對該個人資料管理負責人的姓名或名稱通知本人,或使本人能夠容易知悉的情況

### 第五條(個人資料的揭露)

本服務在本人提出個人資料揭露請求時,將及時向本人揭露相關資訊。\
但若揭露符合以下任一情形,可能不揭露全部或部分內容。若決定不揭露,將及時告知本人相關情況。\
此外,揭露個人資料時,每次將收取 1,500 日圓的手續費。

1. 可能損害本人或第三方的生命、身體、財產或其他權益的情況
2. 可能對本服務營運的正常實施造成顯著妨礙的情況
3. 其他違反法令的情況
4. 儘管有上述規定,原則上不揭露歷史資訊及特徵資訊等以外的個人資料以外的資訊。

### 第六條(個人資料的更正或刪除)

1. 若使用者認為本服務持有的自身個人資料有誤,除以下情況外,可依照本服務規定的程序要求本服務更正個人資料。
   1. 因違規行為等原因導致帳號處於停權狀態的情況
   2. 我方認為不適當的情況
   3. 技術上無法實現的情況
2. 本服務在收到使用者上述請求後,若認為有必要回應該請求,將及時更正相關個人資料,並將此告知使用者。

### 第七條(本政策的變更)

1. 本政策內容可能在不另行通知使用者的情況下進行變更。
2. 除本服務另行規定外,修訂後的本政策自[本網站](https://docs.mk-juice.dev/)刊登之時起生效。
