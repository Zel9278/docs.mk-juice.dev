# 小說標記・小說閱讀器

可為貼文加上「小說」標記,並在專用的小說閱讀器中閱讀。閱讀器支援直排的文庫本風格顯示,以及注音(ruby)和[青空文庫](https://www.aozora.gr.jp/)標記。

## 加上小說標記

- 在發文表單中,開啟 AI 生成內容標記開關旁的「標記為小說」後發文。
- 發文後,也可以在貼文的「…」選單中透過「標記為小說」/「取消小說標記」切換。
- 帶有標記的貼文會顯示書本徽章。

### 以 .txt 檔案發布長篇

超過貼文內文字數上限的長篇,可將內文作為 .txt 檔案附加,小說閱讀器會將該檔案作為內文讀取。

- 支援 UTF-8 與 Shift_JIS 編碼(自動判別)。
- 也可以為 Drive 中的 .txt 檔案加上小說標記。將帶標記的檔案附加到貼文時,貼文也會自動帶上小說標記。
- 附加了多個 .txt 檔案時,優先使用帶小說標記的檔案。

## 在小說閱讀器中閱讀

帶標記的貼文可透過書本徽章,或貼文「…」選單中的「以小說模式閱讀」在小說閱讀器中開啟(`/notes/<貼文ID>/novel-viewer`)。

### 橫排與直排

- **橫排**: 一般的捲動顯示。每個章節的分界處會顯示目錄以及前後章節的連結。
- **直排**: 像文庫本一樣從右向左翻頁的顯示方式。畫面夠寬時會以跨頁(兩頁)形式顯示。

### 章節與目錄

內文中單獨一行的 `---`(三個以上連字號)會作為章節分隔。沒有分隔時,全文視為一個章節。可以透過目錄跳轉章節。

### 顯示設定

可在閱讀器的「顯示設定」中變更以下內容。設定依裝置儲存。

- 文字大小(小・標準・大・特大)
- 字體(標準・明體・黑體)
- 背景(自動・白・棕褐・黑・自訂)。自訂時可自由選擇文字顏色與背景顏色
- 段落縮排: 自動為行首沒有全形空格的段落補上縮排。已經縮排的段落維持不變
- 解析青空文庫標記: 支援以下標記
  - 注音: `｜漢字《かんじ》` 或 `漢字《かんじ》`(緊接在前的連續漢字會成為注音對象)
  - 縮排: `［＃ここから2字下げ］`～`［＃ここで字下げ終わり］`
  - 開頭的「テキスト中に現れる記号について」凡例區塊會從內文中移除
  - 不支援的標記不會顯示

### 書籤

直排模式下閱讀到的頁面會被自動記住,下次開啟時可以接著閱讀(依裝置儲存,最多最近 50 部作品)。

## 在時間軸中的顯示

- 在一般時間軸(首頁・本機・社群・全域)的選單中選擇「僅顯示小說」,即可只顯示帶小說標記的貼文。
- 帶小說標記的貼文即使沒有附件,也會顯示在[媒體時間軸](./media-timeline.md)中。

## 與其他實例的聯合

小說標記會作為 Juice Server 獨有的 ActivityPub 屬性傳送給聯合的實例。不支援的實例會直接忽略。

針對無法解析該屬性的非 JUICE 實例,也提供了在聯合時以 CW 形式傳送小說資訊的後備設定(控制台的 JUICE 設定,預設停用)。其機制與 [AI 生成內容標記](./ai-generated-flag.md)的 CW 後備相同,同時符合兩者的貼文以 AI 生成內容為優先。
