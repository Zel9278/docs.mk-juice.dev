# 小說標記・小說閱讀器

可為貼文加上「小說」標記,並在專用的小說閱讀器中閱讀。閱讀器支援直排的文庫本風格顯示,以及注音・著重號等[青空文庫](https://www.aozora.gr.jp/)標記和 pixiv 小說標記。

## 以小說形式發文

### 加上小說標記

- **發文表單**: 點擊下方工具列中的書本圖示(位於 AI 生成內容按鈕旁)將其開啟。
- **發文之後**: 在自己貼文的「…」選單中選擇「標記為小說」/「取消小說標記」,即可隨時加上或取消。
- **Drive 中的 .txt 檔案**: 在 Drive 中開啟 .txt 檔案的選單,選擇「標記為小說」。將帶標記的檔案附加到貼文時,貼文也會自動帶上小說標記(也可以手動取消)。

帶有小說標記的貼文會有以下表現:

- 在時間軸和貼文詳情中,名字旁邊會顯示書本徽章。點擊徽章即可在小說閱讀器中開啟。
- 也可以透過「…」選單中的「以小說模式閱讀」開啟小說閱讀器。
- 即使沒有附件,也會顯示在[媒體時間軸](./media-timeline.md)中。
- 可以透過一般時間軸(首頁・本機・社群・全域)選單中的「僅顯示小說」進行篩選。

### 內文放在哪裡

- **短篇**: 直接寫在貼文內文中。
- **長篇**: 將內文存成 .txt 檔案並附加。這樣也能閱讀超過貼文字數上限的長篇。
  - 編碼支援 UTF-8・Shift_JIS・EUC-JP(自動判別)。
  - 附加了 .txt 檔案時,會顯示 .txt 檔案的內容作為小說,而不是貼文內文。
  - 附加了多個 .txt 檔案時,優先使用在 Drive 中加上小說標記的檔案。
- **使用[小說編輯器](./novel-editor.md)撰寫**: 可以藉助寫法輸入輔助・預覽・發布前檢查進行撰寫。寫完的內文可以產生 .txt 檔案,並加上小說標記發布。

## 內文中可用的寫法

小說閱讀器會以 **原樣的文字** 顯示內文。MFM(連結・提及・主題標籤・自訂表情符號・`$[…]` 函式・`<center>` 等)不會被解析,會直接以文字顯示。在此基礎上,只有以下小說中常用的寫法會生效。

### 章節與分頁

| 寫法 | 意義 |
| --- | --- |
| `---`(單獨一行,三個以上連字號) | 章節分隔。會作為章節列在目錄中,橫排時每個章節都會顯示「上一章」「目錄」「下一章」 |
| `[newpage]`(單獨一行) | 分頁(與 pixiv 小說相同)。橫排時每次顯示一頁,透過「上一頁」/「下一頁」切換;直排時從這裡開始必定進入下一頁 |
| `[chapter:標題]` | 章節標題。在內文中作為標題顯示,目錄中也會以此名稱列出(沒有標題的章節顯示為「第N章」) |

```text
[chapter:一　開始]
內文……

---

[chapter:二　繼續]
內文……

[newpage]

[chapter:三　下一頁的章節]
內文……
```

::: tip
如果第一章也加上 `[chapter:…]`,目錄中就會顯示章節名稱,而不是「第1章」。
:::

### 注音(ruby)

| 寫法 | 範例 |
| --- | --- |
| `｜基底《讀音》`(青空文庫) | `｜潮待ち便《しおまちびん》` |
| `漢字《讀音》`(省略 ｜) | `潮見島《しおみじま》` |
| `＊基底《讀音》`・`*基底《讀音》`・`\|基底《讀音》` | `＊御立会《おたちあい》` |
| `[[rb:基底 > 讀音]]`(pixiv) | `[[rb:灯台守 > とうだいもり]]` |
| `$[ruby 基底 讀音]`(MFM) | `$[ruby 真鍮 しんちゅう]` |

::: warning
省略 `｜` 等標記時,注音 **只會加在《》緊接在前的連續漢字上**(青空文庫的規則)。例如 `潮待ち便《しおまちびん》` 中漢字在「ち」處中斷,因此只有「便」會加上注音。為包含非漢字的詞語加注音時,請務必像 `｜潮待ち便《しおまちびん》` 這樣標明起始位置。
:::

### 著重號(青空文庫)

| 寫法 | 範例 |
| --- | --- |
| `［＃「對象」に傍点］` | `潮待ち便［＃「潮待ち便」に傍点］` |
| `［＃傍点］…［＃傍点終わり］` | `［＃傍点］ここだけ［＃傍点終わり］` |

- 青空文庫的正式寫法是將對象文字放在注記的 **緊前方**(放在緊後方也會生效)。
- 除 `傍点`(黑芝麻點)外,還可以使用 `白ゴマ傍点`(白芝麻點)・`丸傍点`(黑圓點)・`白丸傍点`(白圓點)。
- 直排時顯示在文字右側,橫排時顯示在上方。

### 縮排(青空文庫)

```text
［＃ここから2字下げ］
需要縮排的行
需要縮排的行
［＃ここで字下げ終わり］
```

區塊內每一行的開頭會依數字插入相應數量的全形空格。

### 文字裝飾

| 寫法 | 顯示 |
| --- | --- |
| `**粗體**` | **粗體** |
| `*斜體*` | *斜體* |
| `~~刪除線~~` | ~~刪除線~~ |

- 可以巢狀使用(例: `**粗體中的~~刪除線~~**`)。裝飾中也可以加入注音。
- **只有在同一行內閉合時** 才會生效。跨越換行時會直接顯示符號。
- 像 `* 注` 這樣,符號緊後方(或緊前方)是空格時,會被視為一般符號而非裝飾。

### 其他 pixiv 小說寫法

| 寫法 | 顯示 |
| --- | --- |
| `[[jumpuri:顯示名稱 > URL]]` | 只顯示名稱文字(不會加上連結) |
| `[jump:N]` | 不顯示 |
| `[pixivimage:…]` | 不顯示 |

### 關於青空文庫格式的文字

- 開頭的「【テキスト中に現れる記号について】」凡例區塊(由橫線包圍的部分)會被自動移除。
- 此處未列出的 `［＃…］` 注記(不支援的注記)會連同注記一起從顯示中消失。

如果讀者在顯示設定中關閉了「解析青空文庫標記」,《》注音・著重號・縮排注記將不會被解析,而是直接以文字顯示(預設開啟)。

### 自動縮排

讀者的顯示設定「段落縮排」開啟時(預設),行首沒有空格的行會自動縮排一個全形空格。以下列字元開頭的行不會縮排:

- 已經以空格(全形・半形)開頭的行
- 左括號: `「 『 （ ( 〔 ［ [ ｛ { 〈 《 【 〘 〖 ｢ “ ‘`
- 符號: `・ ･ ― — ﹅ ﹆ ● ○ ◎ ◯ ◆ ◇ ■ □ ★ ☆ ※ 、 。 ，`

這是為了防止對話(「」)和場景切換符號(◆・＊・●○ 等)的行被擅自縮排。另外,以注音寫法 `[[rb:…]]` 開頭的行會作為一般文字行進行縮排。

### 直排時的顯示

- 英文字母・數字會逐個豎立排列。
- `…` `‥` `―` `—` 以及半形的 `( ) [ ] { } < > - ~ =` 等,會為直排旋轉 90 度顯示。
- 當注音跨越頁面邊界時,會在其前方分頁以免被截斷(因此每頁的寬度可能略有不同)。

### 發文前檢查清單

- 已加上小說標記(或已附加帶小說標記的 .txt 檔案)
- 包含非漢字的詞語的注音已用 `｜` 標明起始位置
- 如需在目錄中顯示章節名稱,第一章也已加上 `[chapter:…]`
- 粗體等裝飾已在同一行內閉合
- 長篇已作為 .txt 檔案附加

## 在小說閱讀器中閱讀

- **橫排/直排**: 可以切換。直排是像文庫本一樣從右向左翻頁的顯示方式,畫面夠寬時會以跨頁(兩頁)形式顯示。
- **翻頁方式**(直排): 除頁面下方的按鈕外,還可以滑動(向右滑動為下一頁)或使用鍵盤的 ←(下一頁)/→(上一頁)翻頁。
- **全螢幕閱讀**: 只將內文鋪滿整個畫面顯示。全螢幕狀態下也可以開啟目錄・顯示設定,並切換橫排/直排。
- **顯示設定**: 可以變更文字大小、字體(標準・明體・黑體)、背景(自動・白・棕褐・黑・自訂)、段落縮排、青空文庫標記的解析。設定依裝置儲存。
- **書籤**: 會記住直排時閱讀到的頁面,下次開啟時從該處繼續(依裝置儲存,最多最近 50 部作品)。
- **字數與閱讀時間估算**: 顯示在作者名稱下方。不計算空格・換行・注音讀音,依每分鐘約 500 字計算。
- 即使改變視窗大小,也會在保持閱讀位置的同時重新分頁。

## 在其他伺服器上的顯示

小說標記會作為 Juice Server 獨有的 ActivityPub 屬性傳送給聯合的伺服器。JUICE 之間會以小說形式聯合,不支援的伺服器會直接忽略。

- 如果管理員開啟了「小說貼文的 CW 後備」(控制台的 JUICE 設定,預設停用),在非 JUICE 伺服器上會帶有寫著「小說」的 CW 顯示。其機制與 [AI 生成內容標記](./ai-generated-flag.md)的 CW 後備相同,同時符合兩者的貼文以 AI 生成內容為優先。
- 在非 JUICE 伺服器上,內文會作為一般貼文顯示,因此 `［＃…］` 和 `[newpage]` 等寫法會直接以文字顯示。
