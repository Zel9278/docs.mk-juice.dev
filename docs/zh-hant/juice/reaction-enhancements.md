# 表情回應功能增強

針對標準 Misskey 表情回應功能的若干增強。

## 跟隨回應

點擊貼文上其他使用者已新增的表情回應,即可為自己也新增相同的表情回應。會套用與一般表情回應相同的權限檢查(角色限制、敏感內容、僅限本地等)。

由於跟隨使用遠端實例自訂表情符號所做的回應,可能構成在未經著作權人許可的情況下使用該實例的表情符號圖片,因此該功能需要在控制面板的 JUICE 設定中手動啟用(預設關閉)。

## 遠端自訂表情回應的解析

當表情回應字串(`:name@host:`)指定了遠端主機上的自訂表情符號時,僅限本地使用者發出的回應,會按照「指定主機 → 本地 → 貼文作者所在主機」的順序尋找並識別該表情符號。

對於從遠端接收到的表情回應,出於防止冒充的考量,仍按以往方式僅以回應者本人所在主機為準。若在 JUICE 設定中關閉此功能,同樣會恢復為僅以本人主機(即本地)為準的原有行為。

## 表情回應的表情符號資訊

用於查看表情回應所用表情符號資訊(授權等)的「資訊」選單,現已支援不僅限於本地自訂表情符號,也可用於透過遠端實例自訂表情符號所做的回應。

## 表情回應搜尋

搜尋頁面新增了專用分頁「表情回應」,可依您自己新增的表情回應篩選貼文。

- 可篩選「新增過任意表情回應的貼文」,或選擇特定表情回應進行篩選。
- 同樣支援與貼文搜尋相同的進階搜尋選項、日期時間範圍、搜尋範圍,以及 URL/@使用者/#標籤的自動連結。
- 出於隱私考量,篩選對象僅限您自己的表情回應。
