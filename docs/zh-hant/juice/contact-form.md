# 聯絡表單

無需登入即可提交的聯絡表單(管理員也可以設定為必須登入才能提交)。

## 提交方法

- 選擇分類和回覆方式(電子郵件地址,或 Misskey 使用者名稱)後提交。
- 可選擇在內文中附加作業系統、瀏覽器、螢幕尺寸等裝置資訊,便於回報技術性問題時使用。

## 管理端處理方式

- 控制面板中提供清單及詳情頁面,可管理狀態(未處理・處理中・已處理・已關閉)、填寫管理員備註、指派負責人。
- 收到新的聯絡表單提交時,可透過 System Webhook 發送通知(`receivedContactForm` 事件)。
- 分類可在控制面板的 JUICE 設定中進行新增、編輯、排序及啟用/停用切換。
- 內文的最大字數也可在 JUICE 設定中調整(預設 10,000 字)。

## 關於權限

處理操作(變更狀態、指派負責人、刪除)不僅限於板主,也可依角色單獨授予權限。但由於聯絡表單內容中包含電子郵件地址、IP 位址等個人資訊,非板主的負責人在查看時,這些資訊將被遮蔽顯示(處理權限本身可以委派,但個人資訊的查看僅限板主及管理員)。

擁有該權限的非板主使用者,可直接透過「工具」選單進入清單頁面,無需經過控制面板。
