# 更新日誌

關於 misskey-juice 中 JUICE 獨有功能的主要更新日誌。不包含源自官方 Misskey 的變更內容。完整歷史記錄請參閱 [GitHub 發布頁面](https://github.com/Zel9278/misskey-juice/releases)。

> [!note]
> 本頁面為手動更新,可能無法及時反映[日語更新日誌](../../juice/changelog.md)的最新內容。如需最新資訊,請同時參閱日語頁面(或上方 GitHub 發布頁面)。

## v2026.9.1-juice+3.16

- 新增[小說編輯器](./novel-editor.md)(`/novel-editor`)。為寫法著色,並可透過按鈕輸入注音・著重號・裝飾・縮排・章節標題・分隔・分頁・破折號・刪節號。支援自動儲存在瀏覽器中的依作品草稿、顯示各章節字數的目錄、字數・稿紙換算・目標字數、尋找與取代、專注模式、與小說閱讀器外觀相同的預覽,以及發布前檢查。還可以讀取・儲存 .txt,並將內文產生 .txt 檔案加上小說標記發布
- 大幅增強[繪畫聊天](./draw-room.md):矩形・套索選取與移動工具、選取線條的旋轉・刪除,套索填色・油漆桶・暈染畫筆・像素畫筆・只在線內塗色,筆與橡皮擦粗細分開設定、抓手工具、畫布旋轉、PC 上的縮放與移動操作,像素畫放大模式與像素格線(最大放大 3200%),房主可以清除他人的圖層或切換到觀戰模式,聊天支援表情符號並顯示時間,開啟房間時顯示載入中
- 可以在 JUICE 設定中依使用者選擇 MFM 搜尋框(「… 検索」)使用的搜尋引擎: Google・Yahoo!・Yahoo! JAPAN・Bing・DuckDuckGo・Kagi・Brave Search・Startpage・Ecosia・Perplexity・自訂 URL
- 在智慧型手機等窄螢幕上,繪畫聊天・小說編輯器的按鈕會顯示名稱,頁面標題列的按鈕整合為帶名稱的選單。在智慧型手機・平板上加大了調整視窗大小的控點
- 修正繪畫聊天結束後「儲存到雲端硬碟」「發布為貼文」「下載」無法正常運作的問題,以及結束後觀看者・線上狀態仍殘留在圖層清單中的問題
- 修正小說閱讀器中直排頁面超出畫面高度、直排翻頁後切換到橫排時內文不顯示、橫排時窄螢幕下章節切換按鈕被截斷的問題

## v2026.9.1-juice+3.15

- 新增[繪畫聊天](./draw-room.md)。可以建立房間,讓多人在同一張畫布上繪畫。公開範圍・可繪畫人數上限・畫布大小由房主決定,房間已滿時也可以作為觀看者進入。支援依使用者區分的圖層、筆壓、滴管、縮放與全局地圖、顯示其他人的游標和線上狀態,以及將畫布儲存・發布・下載為圖片(PNG・WebP・JPEG)
- 在控制台的 JUICE 設定中新增繪畫聊天的啟用/停用,在角色政策中新增「建立繪畫聊天房間」「繪畫聊天畫布尺寸上限」
- 可以[檢舉](./abuse-report.md)繪畫聊天房間及其中的聊天發言。版主可以刪除有問題的房間(即使正在進行中),刪除會記錄在管理日誌中

## v2026.9.1-juice+3.14

- [小說閱讀器](./novel.md)的內文不再解析 MFM。連結・提及・自訂表情符號等依原寫法顯示,只有注音(MFM・青空文庫標記・pixiv 的 `[[rb:]]`)以及粗體・斜體・刪除線會生效
- 小說閱讀器支援 pixiv 小說寫法。`[newpage]` 用於分頁,橫排時每次顯示一頁並可透過前後頁按鈕切換;`[chapter:標題]` 用作目錄中的章節名稱
- 支援青空文庫標記的著重號(黑芝麻點・白芝麻點・黑圓點・白圓點)
- 小說閱讀器新增全螢幕閱讀,以及內文字數和預估閱讀時間的顯示
- 可自動判別並讀取 EUC-JP 編碼的 .txt 檔案。注音基底的起始標記除 ｜ 外,也接受 ＊・*・|
- 段落自動縮排時,以「 等左括號或間隔號・破折號・●○ 等符號開頭的行不再縮排
- 修正直排時的多個問題: …、― 和半形括號等橫向顯示;改變視窗大小時分頁和閱讀位置錯位;頁面邊緣露出相鄰頁面注音的殘片;使用瀏覽器頁內搜尋等後左右頁面內容錯位

## v2026.9.1-juice+3.13

- 新增[小說標記・小說閱讀器](./novel.md)。可為貼文和 Drive 中的 .txt 檔案加上「小說」標記,帶標記的貼文可在專用閱讀器中以橫排/直排(文庫本風格翻頁・跨頁顯示)閱讀。支援依章節的目錄・注音・青空文庫標記・段落縮排・文字大小/字體/背景・書籤,並可將附加的 .txt 檔案作為內文讀取,因此也能發布超過字數上限的長篇
- 在一般時間軸的選單中新增「僅顯示小說」。帶小說標記的貼文即使沒有附件,也會顯示在[媒體時間軸](./media-timeline.md)中
- 針對無法解析小說標記的非 JUICE 實例,新增在聯合時以 CW 形式傳送小說資訊的後備設定(預設停用)
- 修正應用程式內 JUICE 介紹頁面中,連結登入項目的較長英文字串超出卡片範圍的問題
