# 更新日誌

關於 misskey-juice 中 JUICE 獨有功能的主要更新日誌。不包含源自官方 Misskey 的變更內容。完整歷史記錄請參閱 [GitHub 發布頁面](https://github.com/Zel9278/misskey-juice/releases)。

> [!note]
> 本頁面為手動更新,可能無法及時反映[日語更新日誌](../../juice/changelog.md)的最新內容。如需最新資訊,請同時參閱日語頁面(或上方 GitHub 發布頁面)。

## v2026.9.0-juice+3.5

- 修復在中繼/媒體時間軸中重新整理頁面時,會意外跳轉回首頁時間軸的問題
- 在設定的「JUICE」頁面的「要顯示的標籤」中,新增可單獨隱藏時間軸標籤列中顯示的清單・天線・頻道切換捷徑圖示的選項
- 修復透過中繼轉發的貼文在 LD-Signature 驗證過程中發生錯誤時,導致貼文接收處理持續失敗的問題

## v2026.9.0-juice+3.4

- 新增[媒體時間軸](./media-timeline.md),以 PixelFed 風格的網格/輪播形式集中顯示帶附件貼文的專用時間軸(僅在管理員啟用後可用)。影片・音訊皆可內嵌播放,還能依貼文排除顯示
- 變更為在燈箱・媒體時間軸的所有內嵌播放之間共享音量設定(儲存在本機本地)
- 新增可在 `/settings/juice` 中依使用者個別隱藏時間軸分頁列中顯示的時間軸

## v2026.9.0-juice+3.3

- 修復表情申請・審批式註冊申請等的未處理橫幅,在處理完成後於控制面板保持開啟期間不會消失的問題
- 修復智慧型手機上導覽列・表情面板・小工具的排序,在觸控操作(尤其是長按)下無法正常運作的問題
- 修復註冊後個人資料設定中,在橫向且縱向空間較窄的螢幕上,更換頭像・儲存等按鈕與底部「返回」/「繼續」按鈕重疊顯示的問題

## v2026.9.0-juice+3.2

- 表情申請・頭像裝飾申請的新申請通知、審批式註冊申請、聯絡表單的新提交通知,現在也會保留在通常的通知清單(🔔)中,而不僅限於即時提示・橫幅。非版主的角色政策持有者也能在整個應用程式內隨時收到即時通知
- [表情申請](./emoji-request.md)・頭像裝飾申請,在審核等待期間可由申請者本人取消
- 歡迎頁面・「新增帳戶」選單中的「使用邀請碼註冊」按鈕,以及「探索其他伺服器」按鈕,均可分別透過管理員設定隱藏
- 新增以 JUICE 品牌色橘色為基調的標準主題「Juice Orange」(淺色/深色),並將其設為標準初始主題
- [中繼時間軸](./relay-timeline.md)現會顯示每則貼文是透過哪個中繼送達的
- 修復[顯示語言篩選](./post-language.md#時間軸語言篩選)未套用於部分時間軸・即時串流的問題。同時調整了未指定語言的貼文的處理方式,以及是否始終顯示自己貼文的設定
- 為「刪除並編輯」表單新增關閉前的確認對話框以防止誤操作,並修復未編輯關閉時內容遺失的問題
- 修復跟隨回應使用遠端表情符號時,在官方 Misskey 等平台上被替換為愛心圖示的問題
- 新增英語・韓語・簡體中文翻譯至 JUICE 獨有項目

## v2026.9.0-juice+3.1

- [表情符號資訊選單](./reaction-enhancements.md#表情符號資訊選單)現已支援不僅限於表情回應,也可用於嵌入在貼文內文・CW・個人檔案等處的表情符號
- [公告表情回應功能](./announcement-reaction.md)中,可新增的表情回應種類上限現可在角色政策中設定(預設 20 種)
- 在跟隨回應中使用遠端表情符號時的著作權相關提示,現已同時新增至管理介面與應用程式內[About JUICE 頁面](./about-page.md)
- 修復我的最愛 Deck 欄目的顯示・即時同步相關問題
- 將工作佇列小工具的提示音設定,改為開關切換與音效選擇分離的方式

## v2026.9.0-juice+3.0

跟進官方 Misskey 2026.9.0 的重大版本。主要新增功能:

- [表情回應功能增強](./reaction-enhancements.md)(跟隨回應、遠端自訂表情回應解析、表情回應搜尋分頁等)
- [貼文語言](./post-language.md)
- [貼文搜尋增強](./note-search-enhancements.md)
- [聯絡表單](./contact-form.md)
- 為表情符號・頭像裝飾申請新增批次申請、替換申請及核准時編輯功能
- [使用者排行榜](./user-ranking.md)的顯示人數現可在 JUICE 設定中調整(預設 3 人)
- 擴充審核・管理員通知(表情符號申請、聯絡表單等新提交內容會即時顯示在控制面板中)
- 系統郵件多語言支援
- 各類安全性增強(擴大 captcha 適用範圍、登入失敗時通知本人、審核處理的互斥控制等)
- 為 Deck UI 的欄目新增「收藏」
- 啟動載入畫面新增啟動日誌顯示及自訂啟動語設定
- 工作佇列小工具的提示音現可更換為自選音效
