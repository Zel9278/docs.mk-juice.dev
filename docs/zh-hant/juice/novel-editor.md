# 小說編輯器

用於撰寫[小說標記・小說閱讀器](./novel.md)所用內文的編輯器。可從導覽選單開啟(`/novel-editor`)。寫完的內文可以直接產生 .txt 檔案,並加上小說標記發布。

## 作品與草稿

- 每部作品都有各自的標題・內文・目標字數,可以在「作品」中切換,或建立「新作品」。
- 草稿會**自動儲存在目前的瀏覽器中**,並與同一瀏覽器的其他分頁同步。
- 由於儲存在瀏覽器中,不會與其他裝置或瀏覽器共用。清除瀏覽器資料時草稿也會被刪除,重要的作品請透過「儲存為 .txt」另行保存。如果超出瀏覽器的儲存容量而無法儲存,畫面上會顯示提示。

## 撰寫

內文中的寫法(注音・著重號等注記、章節標題、分隔、分頁、粗體等)會以顏色標示,便於區分。以下寫法可以透過按鈕輸入:

| 按鈕 | 輸入內容 |
| --- | --- |
| 注音 | 為選取的文字加上注音(以 `[[rb:基底 > 讀音]]` 的形式插入) |
| 著重號 | 為選取的文字加上著重號(﹅)・白芝麻著重號(﹆)・圓點著重號(●)・白圓點著重號(○) |
| 裝飾 | 將選取的文字設為粗體・斜體・刪除線 |
| 縮排 | 將選取的行統一縮排指定的字數 |
| 章節標題 | 插入從此處開始的章節標題(`[chapter:…]`) |
| 分隔 | 在此處分隔章節(`---`) |
| 分頁 | 在此處換頁(`[newpage]`) |
| 破折號・刪節號 | 輸入 `――`・`……` |

各寫法的詳細意義請參閱[小說標記・小說閱讀器](./novel.md)。

### 顯示與輸入設定

- 換行時自動縮排段首
- 自動補齊括號
- 將正在撰寫的行保持在畫面中央
- 並排顯示預覽
- 字體・文字大小・行高

開啟「專注模式」後,編輯器會全螢幕顯示。「尋找與取代」也支援區分大小寫・規則運算式・依單字搜尋。

## 目錄與字數

- 目錄中會顯示各章節的字數,點擊即可跳至該位置。
- 會顯示字數、稿紙換算(400 字稿紙,依每行 20 字、每段換行計算的張數)以及選取範圍的字數。字數不包括空格・換行・注音讀音・注記等寫法。
- 設定「目標字數」後,會顯示完成進度。

## 預覽

可以用與小說閱讀器相同的外觀進行預覽。寬螢幕時顯示在編輯器旁邊,窄螢幕時在獨立的視窗中顯示。撰寫過程中也會即時反映到預覽中。

## 發布前檢查

「發布前檢查」會將需要注意的地方列成清單,在獨立的視窗中顯示。點擊項目即可跳至編輯器中的對應行。撰寫過程中結果也會更新,發布時如有需要注意的地方也會提示(也可以透過「仍要發布」直接發布)。主要會指出以下情況:

- 注音的加上方式(《》前沒有漢字、包含非漢字的詞語沒有 `｜`、注音寫法錯誤)
- 括號未閉合,或存在沒有對應左括號的右括號
- 未在同一行內閉合的粗體・刪除線・著重號注記,以及未閉合的縮排注記
- 小說閱讀器不支援的注記(不支援 `［＃改ページ］`,會提示改用 `[newpage]`)
- 不是單獨一行的 `[newpage]`、沒有內容的章節、第一章沒有 `[chapter:…]`
- 只用了一個刪節號・破折號、使用了「・・・」、！？後面沒有全形空格

## 讀取・儲存・發布

- **讀取**: 將裝置或雲端硬碟中的 .txt 檔案作為新作品開啟。編碼會自動判別。
- **儲存為 .txt**: 將內文儲存為 .txt 檔案。
- **發布**: 將內文產生 .txt 檔案上傳到雲端硬碟,並加上小說標記附加到發文表單中。
