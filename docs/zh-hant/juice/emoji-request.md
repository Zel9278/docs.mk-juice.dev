# 表情符號申請

允許一般使用者申請新增自訂表情符號的功能。

## 申請方法

在表情符號申請頁面填寫以下內容進行申請:

- 表情符號圖片
- 名稱
- 分類
- 授權

申請將保持待審核狀態,直至被駁回或核准。一經核准,即可立即作為自訂表情符號使用。若被駁回,將通知駁回理由。如需再次申請,請以新申請的形式重新提交。

## 申請數量限制

同時可提交的申請(待審核)數量有限制(預設為 3 個)。此外,為防止連續申請,還設有速率限制。

## 申請圖片的處理

申請時,您可以選擇審核完成後是否刪除圖片。若勾選此項,無論核准還是駁回,審核完成後雲端硬碟檔案都會被刪除(核准時圖片已被複製至表情符號,因此刪除原圖片不會影響表情符號本身)。
