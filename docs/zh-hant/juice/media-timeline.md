# 媒體時間軸

以 PixelFed 風格的網格/輪播形式,集中顯示帶附件貼文的專用時間軸。僅在管理員從 JUICE 獨有功能設定中啟用後才可使用(參見[JUICE 獨有功能設定](./settings.md))。

## 顯示範圍

- 顯示至少附帶一個檔案、公開範圍為「公開」的貼文。
- 附帶多個檔案的貼文會以可滑動切換的輪播形式顯示。

## 內嵌播放

帶有影片或音訊的貼文,無需開啟放大顯示(燈箱)即可直接在時間軸上播放。

- 影片配有專用操作列,支援循環播放、調整播放速度、子母畫面、放大顯示等功能。
- 音訊會顯示與燈箱相同的視覺化效果(發文者頭像+波形)和控制列。
- 音量設定在燈箱與媒體時間軸的所有內嵌播放之間共享(儲存在本機本地,調整一次後,之後開啟任何影片/音訊都會維持相同音量)。

## 依貼文排除顯示

在發文表單的「...」選單中選擇「不在媒體時間軸中顯示」,即可將該貼文從媒體時間軸中排除。適用於美食照片等不希望出現在媒體時間軸中的貼文。

此設定僅影響媒體時間軸,不會影響首頁、本地等一般時間軸,也不會影響個人檔案的「檔案」分頁、搜尋結果等其他檔案篩選顯示。

## 分頁的顯示與隱藏

是否在時間軸頁面的分頁列中顯示媒體時間軸分頁,可以在 `/settings/juice` 中依每位使用者個別切換。詳情請參見[JUICE 獨有功能設定](./settings.md)。
