# 第三方登入

允許您關聯 Discord・Google・GitHub・GitLab・Microsoft 帳號,並使用這些帳號登入的功能。

## 設定關聯

在設定的「JUICE」頁面(「帳號」分類)中,可以關聯・解除關聯各服務帳號。關聯帳號與將其用作登入方式是兩個獨立的開關。

啟用為登入方式後,登入頁面會顯示對應服務商的按鈕,可以透過該關聯帳號進行登入。

## 安全性限制

要將第三方登入用作登入方式,需要同時滿足以下兩個條件:

- **您的 Misskey 帳號已啟用兩步驟驗證(2FA)**
- **已單獨開啟將其用作登入方式的選項**(僅關聯帳號不會自動成為登入方式)

這是為了防止僅因關聯帳號(例如 Google 帳號)被盜用,就導致 Misskey 帳號也被入侵。此限制在伺服器端強制執行,作為應對官方 Misskey 過去廢除類似功能所依據理由的對策。

## 支援的服務商

- Discord
- Google
- GitHub
- GitLab
- Microsoft

僅管理員在控制面板 JUICE 設定中啟用的服務商可供使用。
