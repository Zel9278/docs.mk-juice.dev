# MIDI 播放器

用於播放貼文附件中 MIDI 檔案(.mid/.midi)的輕量級內建播放器。無需外部音色庫,僅透過 Web Audio API 的振盪器合成即可運作。

## 特點

- 支援依 GM(General MIDI)音色家族分別進行合成,不同樂器會呈現不同音色。
- 支援控制變化(Control Change)・彎音輪(Pitch Bend)。
- 128 鍵鍵盤視覺化介面,依音軌分色顯示目前正在發聲的音符。
- 具備音量調整・進度條。
- 即時顯示 BPM 與同時發聲數(正在播放的音符數)。
- 基於 AudioWorklet 的峰值限制器,防止破音。
- 支援 Media Session API,可在手機鎖定畫面或通知欄中進行播放/暫停等操作。

## 可播放的檔案大小上限

由於解析並播放音符事件數量極多的檔案(如 Black MIDI)可能導致瀏覽器當機,因此設有允許播放的最大檔案大小限制(預設 500KB)。此上限可由管理員在控制面板的 JUICE 設定中調整。超過上限的檔案將作為一般附件處理,而非交由播放器播放。
