# 檢舉

用於檢舉使用者、貼文和聊天訊息的功能。

## 檢舉方法

- 在使用者頁面的「...」選單中選擇「檢舉」,即可開啟針對該使用者的檢舉表單。
- 也可以從貼文或聊天訊息的選單中檢舉,此時目標貼文/訊息會自動關聯到該檢舉。
- 檢舉時可以選擇分類(垃圾訊息、騷擾、冒充等)。分類可以在控制面板的 JUICE 設定中新增、編輯及調整順序。

## 目標內容預覽

檢舉貼文或聊天訊息後,管理員可以在檢舉詳情頁面預覽其內容。對於聊天私訊而言,這是營運方首次能夠檢視訊息內容的途徑,且僅限於被檢舉的情況(通常聊天內容無法從控制面板檢視)。

## 管理端處理

- 控制面板的檢舉清單可以依分類篩選檢視。
- 「工具」選單中提供了直達檢舉管理的快速入口,以及專用頁面(`/abuses-manager`),無需經過整個控制面板即可確認並處理檢舉。
- 新檢舉通知現在不僅會以即時提示的形式出現(僅限開啟控制面板期間),也會保留在一般通知清單(🔔)中,即使離線或重新整理頁面後也能事後查看。

## 封鎖後停權

管理員・版主在停權使用者時,可以先用自己的帳號封鎖該使用者,然後再將其停權,以便提前切斷對處理該檢舉的本人的報復性接觸(提及、追蹤等)。此功能可在控制面板的使用者詳情頁面和使用者選單中使用。
