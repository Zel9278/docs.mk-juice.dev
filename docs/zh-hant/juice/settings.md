# JUICE 獨有功能設定

Juice Server 擁有多個標準 Misskey 中沒有的獨有功能。這些獨有功能的相關設定都集中在控制面板的「**JUICE**」項目中。

## 可設定的主要項目

使用管理員帳號登入後,進入控制面板 → 「JUICE」,即可變更以下獨有功能的啟用・停用及各項選項:

- [審核制註冊](./approval-signup.md)的啟用・停用,註冊理由的必填/選填・最大字數
- 將建立時間未超過指定時長的帳戶發起的追蹤,無論目標使用者是否啟用審核制追蹤都作為需要審核的追蹤請求處理這項功能的啟用・停用,及時長閾值
- [使用者排行榜](./user-ranking.md)的統計週期・顯示人數
- [中繼時間軸](./relay-timeline.md)的啟用・停用
- [媒體時間軸](./media-timeline.md)的啟用・停用
- [表情符號申請](./emoji-request.md)・頭像裝飾申請的啟用・停用,同時申請數量上限
- [LaTeX(數學公式)顯示](./latex.md)的啟用・停用
- [聯絡表單](./contact-form.md)的啟用・停用、分類管理、內文最大字數
- [檢舉](./abuse-report.md)分類管理
- 封鎖利用電子郵件地址別名(Gmail的忽略句點與+標籤)進行的多重帳號註冊(預設為停用。由於兩者的誤判風險不同,忽略句點與+標籤可以分別單獨開關)
- 歡迎頁面・「新增帳戶」選單中「使用邀請碼註冊」按鈕、「探索其他伺服器」按鈕的顯示・隱藏
- 啟動載入畫面顯示的自訂啟動語

個人設定([小工具位置](./widget-position.md)、時間軸分頁列中顯示哪些時間軸及其順序等)與此不同,需在 `/settings/juice` 中另行變更。

各功能的詳細內容,請參閱相應頁面。
