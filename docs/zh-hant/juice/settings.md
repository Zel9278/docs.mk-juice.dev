# JUICE 獨有功能設定

Juice Server 擁有多個標準 Misskey 中沒有的獨有功能。這些獨有功能的相關設定都集中在控制面板的**「JUICE」項目**中。

## 可設定的主要項目

使用管理員帳號登入後,進入控制面板 → 「JUICE」,即可變更以下獨有功能的啟用・停用及各項選項:

- [審核制註冊](./approval-signup.md)的啟用・停用,註冊理由的必填/選填・最大字數
- [使用者排行榜](./user-ranking.md)的統計週期
- [中繼時間軸](./relay-timeline.md)的啟用・停用
- [表情符號申請](./emoji-request.md)的啟用・停用
- [LaTeX(數學公式)顯示](./latex.md)的啟用・停用

個人設定([小工具位置](./widget-position.md)等)與此不同,需在 `/settings/juice` 中另行變更。

各功能的詳細內容,請參閱相應頁面。
