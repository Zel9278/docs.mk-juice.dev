# 貼文語言

允許為每則貼文明確指定語言的功能。以與 Mastodon 相容的格式進行聯合。

## 發文時指定語言

在貼文撰寫介面中,您可以明確指定該貼文的語言(BCP 47 語言標籤)。若未指定,將使用您的顯示語言設定作為預設值。

在 ActivityPub 聯合中,使用 AS2 標準的 `contentMap`(與 Mastodon、Akkoma 相容)。

## 時間軸語言篩選

在 JUICE 獨有功能設定中,您可以依語言篩選首頁、本地、全域時間軸中顯示的貼文。該功能參考了 Mastodon 的「篩選語言」,但存在以下差異:

- 適用於所有時間軸。
- 轉發也會依據被轉發原貼文的語言進行判定。
- 當篩選條件生效(已選擇一個以上語言)時,未指定語言的貼文也會被篩選並隱藏。

您也可以直接在時間軸畫面的「…」選單中切換該設定。

您可以設定在篩選條件生效時,是否始終顯示自己發布的貼文(預設開啟=始終顯示)。關閉後,自己的貼文也會和其他使用者一樣依語言篩選。此設定不影響全域時間軸。

## 搜尋中的語言指定

貼文搜尋・表情回應搜尋的進階搜尋選項中,包含依貼文語言進行篩選的功能。

## 僅顯示本地使用者

首頁時間軸的「…」選單中,有一個僅篩選顯示本地使用者貼文的開關。如果您想暫時隱藏所追蹤的遠端使用者的貼文,可以使用此功能。
