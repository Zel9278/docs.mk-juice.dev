# 第三方登录

允许您关联 Discord・Google・GitHub・GitLab・Microsoft 账号,并使用这些账号登录的功能。

## 设置关联

在设置的"JUICE"页面("账号"分类)中,可以关联・解除关联各服务账号。关联账号与将其用作登录方式是两个独立的开关。

启用为登录方式后,登录页面会显示对应服务商的按钮,可以通过该关联账号进行登录。

## 安全性限制

要将第三方登录用作登录方式,需要同时满足以下两个条件:

- **您的 Misskey 账号已启用两步验证(2FA)**
- **已单独开启将其用作登录方式的选项**(仅关联账号不会自动成为登录方式)

这是为了防止仅因关联账号(例如 Google 账号)被盗用,就导致 Misskey 账号也被侵入。此限制在服务器端强制执行,作为应对官方 Misskey 过去废除类似功能所依据理由的对策。

## 支持的服务商

- Discord
- Google
- GitHub
- GitLab
- Microsoft

仅管理员在控制面板 JUICE 设置中启用的服务商可供使用。
