# 表情回应功能增强

针对标准 Misskey 表情回应功能的若干增强。

## 跟随回应

点击帖子上其他用户已添加的表情回应,即可为自己也添加相同的表情回应。会应用与普通表情回应相同的权限检查(角色限制、敏感内容、仅限本地等)。

由于跟随使用远程实例自定义表情符号所做的回应,可能构成在未经著作权人许可的情况下使用该实例的表情符号图片,因此该功能需要在控制面板的 JUICE 设置中手动启用(默认关闭)。

## 远程自定义表情回应的解析

当表情回应字符串(`:name@host:`)指定了远程主机上的自定义表情符号时,仅限本地用户发出的回应,会按照"指定主机 → 本地 → 帖子作者所在主机"的顺序查找并识别该表情符号。

对于从远程接收到的表情回应,出于防止冒充的考虑,仍按以往方式仅以回应者本人所在主机为准。若在 JUICE 设置中关闭此功能,同样会恢复为仅以本人主机(即本地)为准的原有行为。

## 表情回应的表情符号信息

用于查看表情回应所用表情符号信息(许可协议等)的"信息"菜单,现已支持不仅限于本地自定义表情符号,也可用于通过远程实例自定义表情符号所做的回应。

## 表情回应搜索

搜索页面新增了专用标签页"表情回应",可按您自己添加的表情回应筛选帖子。

- 可筛选"添加过任意表情回应的帖子",或选择特定表情回应进行筛选。
- 同样支持与帖子搜索相同的高级搜索选项、日期时间范围、搜索范围,以及 URL/@用户/#标签的自动链接。
- 出于隐私考虑,筛选对象仅限您自己的表情回应。
