# 联系表单

无需登录即可提交的联系表单(管理员也可以设置为必须登录才能提交)。

## 提交方法

- 选择分类和回复方式(电子邮箱地址,或 Misskey 用户名)后提交。
- 可选择在正文中附加操作系统、浏览器、屏幕尺寸等设备信息,便于报告技术性问题时使用。

## 管理端处理方式

- 控制面板中提供列表及详情页面,可管理状态(未处理・处理中・已处理・已关闭)、填写管理员备注、指派负责人。
- 收到新的联系表单提交时,可通过 System Webhook 发送通知(`receivedContactForm` 事件)。
- 分类可在控制面板的 JUICE 设置中进行新增、编辑、排序及启用/禁用切换。
- 正文的最大字数也可在 JUICE 设置中调整(默认 10,000 字)。

## 关于权限

处理操作(变更状态、指派负责人、删除)不仅限于版主,也可按角色单独授予权限。但由于联系表单内容中包含电子邮箱地址、IP 地址等个人信息,非版主的负责人在查看时,这些信息将被遮蔽显示(处理权限本身可以委派,但个人信息的查看仅限版主及管理员)。

拥有该权限的非版主用户,可直接通过"工具"菜单进入列表页面,无需经过控制面板。
