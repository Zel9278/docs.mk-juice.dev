# JUICE 独有功能设置

Juice Server 拥有多个标准 Misskey 中没有的独有功能。这些独有功能的相关设置都集中在控制面板的「**JUICE**」项目中。

## 可设置的主要项目

使用管理员账号登录后,进入控制面板 → "JUICE",即可更改以下独有功能的启用・禁用及各项选项:

- [审核制注册](./approval-signup.md)的启用・禁用,注册理由的必填/选填・最大字数
- 将创建时间未超过指定时长的账户发起的关注,无论目标用户是否启用审核制关注都作为需要审核的关注请求处理这一功能的启用・禁用,及时长阈值
- [用户排行榜](./user-ranking.md)的统计周期・显示人数
- [中继时间线](./relay-timeline.md)的启用・禁用
- [媒体时间线](./media-timeline.md)的启用・禁用
- [表情符号申请](./emoji-request.md)・头像装饰申请的启用・禁用,同时申请数量上限
- [LaTeX(数学公式)显示](./latex.md)的启用・禁用
- [联系表单](./contact-form.md)的启用・禁用、分类管理、正文最大字数
- [举报](./abuse-report.md)分类管理
- 阻止利用邮箱地址别名(Gmail的忽略点号和+标签)进行的多重账号注册(默认禁用。由于两者的误判风险不同,忽略点号与+标签可以分别单独开关)
- 欢迎页面・「添加账户」菜单中「使用邀请码注册」按钮、「探索其他服务器」按钮的显示・隐藏
- 启动加载画面显示的自定义启动语

个人设置([小组件位置](./widget-position.md)、时间线标签栏中显示哪些时间线及其顺序等)与此不同,需在 `/settings/juice` 中单独更改。

各功能的详细内容,请参阅相应页面。
