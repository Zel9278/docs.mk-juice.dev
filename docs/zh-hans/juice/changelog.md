# 更新日志

关于 misskey-juice 中 JUICE 独有功能的主要更新日志。不包含源自官方 Misskey 的变更内容。完整历史记录请参阅 [GitHub 发布页面](https://github.com/Zel9278/misskey-juice/releases)。

> [!note]
> 本页面为手动更新,可能无法及时反映[日语更新日志](../../juice/changelog.md)的最新内容。如需最新信息,请同时参阅日语页面(或上方 GitHub 发布页面)。

## v2026.9.0-juice+3.2

- 表情申请・头像装饰申请的新申请通知、审批式注册申请、联系表单的新提交通知,现在也会保留在通常的通知列表(🔔)中,而不仅限于实时提示・横幅。非版主的角色策略持有者也能在整个应用内随时收到实时通知
- [表情申请](./emoji-request.md)・头像装饰申请,在审核等待期间可由申请者本人取消
- 欢迎页面・「添加账户」菜单中的「使用邀请码注册」按钮,以及「探索其他服务器」按钮,均可分别通过管理员设置隐藏
- 新增以 JUICE 品牌色橙色为基调的标准主题「Juice Orange」(浅色/深色),并将其设为标准初始主题
- [中继时间线](./relay-timeline.md)现会显示每条帖子是通过哪个中继送达的
- 修复[显示语言过滤](./post-language.md#时间线语言筛选)未应用于部分时间线・实时推送的问题。同时调整了未指定语言的帖子的处理方式,以及是否始终显示自己帖子的设置
- 为「删除并编辑」表单添加关闭前的确认对话框以防止误操作,并修复未编辑关闭时内容丢失的问题
- 修复跟随回应使用远程表情符号时,在官方 Misskey 等平台上被替换为心形图标的问题
- 新增英语・韩语・简体中文翻译至 JUICE 独有项目

## v2026.9.0-juice+3.1

- [表情符号信息菜单](./reaction-enhancements.md#表情符号信息菜单)现已支持不仅限于表情回应,也可用于嵌入在帖子正文・CW・个人资料等处的表情符号
- [公告表情回应功能](./announcement-reaction.md)中,可添加的表情回应种类上限现可在角色策略中设置(默认 20 种)
- 在跟随回应中使用远程表情符号时的著作权相关提示,现已同时添加至管理界面与应用内[About JUICE 页面](./about-page.md)
- 修复收藏 Deck 栏目的显示・实时同步相关问题
- 将任务队列小组件的提示音设置,改为开关切换与音效选择相分离的方式

## v2026.9.0-juice+3.0

跟进官方 Misskey 2026.9.0 的重大版本。主要新增功能:

- [表情回应功能增强](./reaction-enhancements.md)(跟随回应、远程自定义表情回应解析、表情回应搜索标签页等)
- [帖子语言](./post-language.md)
- [帖子搜索增强](./note-search-enhancements.md)
- [联系表单](./contact-form.md)
- 为表情符号・头像装饰申请新增批量申请、替换申请及批准时编辑功能
- [用户排行榜](./user-ranking.md)的显示人数现可在 JUICE 设置中调整(默认 3 人)
- 扩充审核・管理员通知(表情符号申请、联系表单等新提交内容会即时显示在控制面板中)
- 系统邮件多语言支持
- 各类安全性增强(扩大 captcha 应用范围、登录失败时通知本人、审核处理的互斥控制等)
- 为 Deck UI 的栏目新增"收藏"
- 启动加载画面新增启动日志显示及自定义启动语设置
- 任务队列小组件的提示音现可更换为自选音效
