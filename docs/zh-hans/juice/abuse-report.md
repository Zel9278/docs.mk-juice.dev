# 举报

用于举报用户、帖子和聊天消息的功能。

## 举报方法

- 在用户页面的"..."菜单中选择"举报",即可打开针对该用户的举报表单。
- 也可以从帖子或聊天消息的菜单中举报,此时目标帖子/消息会自动关联到该举报。
- 举报时可以选择分类(垃圾信息、骚扰、冒充等)。分类可以在控制面板的 JUICE 设置中添加、编辑和调整顺序。

## 目标内容预览

举报帖子或聊天消息后,管理员可以在举报详情页面预览其内容。对于聊天私信而言,这是运营方首次能够查看消息内容的途径,且仅限于被举报的情况(通常聊天内容无法从控制面板查看)。

## 管理端处理

- 控制面板的举报列表可以按分类筛选查看。
- "工具"菜单中提供了直达举报管理的快捷入口,以及专用页面(`/abuses-manager`),无需经过整个控制面板即可确认和处理举报。
- 新举报通知现在不仅会以实时提示的形式出现(仅限打开控制面板期间),也会保留在常规通知列表(🔔)中,即使离线或刷新页面后也能事后查看。

## 屏蔽后封禁

管理员・版主在封禁用户时,可以先用自己的账号屏蔽该用户,然后再将其封禁,以便提前切断对处理该举报的本人的报复性接触(提及、关注等)。此功能可在控制面板的用户详情页面和用户菜单中使用。
