# MIDI 播放器

用于播放帖子附件中 MIDI 文件(.mid/.midi)的轻量级内置播放器。无需外部音色库,仅通过 Web Audio API 的振荡器合成即可运行。

## 特点

- 支持按 GM(General MIDI)音色族分别进行合成,不同乐器会呈现不同音色。
- 支持控制变化(Control Change)・弯音轮(Pitch Bend)。
- 128 键键盘可视化界面,按音轨分色显示当前正在发声的音符。
- 还配备钢琴卷帘可视化(纵向滚动),以 tick(拍内单位)为基准显示播放位置,因此在有速度变化的曲目中也不易出现偏移。是否启用、卷帘速度、最大同时发声数,均可在设置的"JUICE"页面或播放器内菜单中更改。
- 具备音量调节・进度条。
- 实时显示 BPM 与同时发声数(正在播放的音符数)。
- 基于 AudioWorklet 的峰值限制器,防止破音。
- 支持 Media Session API,可在手机锁屏或通知栏中进行播放/暂停等操作。
- 放大显示已与图片・视频共用同一套灯箱(Lightbox),放大时会继承与内嵌显示相同的播放状态(是否播放中・播放位置・音量)。在灯箱的"…"菜单中也可以更改可视化设置。

::: info 补充
- 在 iPhone/iPad 上,若设备的静音开关处于开启状态,存在无法发声的已知行为。在此情况下会显示提示。
:::

## 可播放的文件大小上限

由于解析并播放音符事件数量极多的文件(如 Black MIDI)可能导致浏览器卡死,因此设有允许播放的最大文件大小限制(默认 500KB)。该上限可由管理员在控制面板的 JUICE 设置中调整。超过上限的文件将作为普通附件处理,而非交由播放器播放。
