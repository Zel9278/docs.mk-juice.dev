# 头像装饰申请

允许普通用户申请添加头像装饰的功能。其机制与[表情符号申请](./emoji-request.md)相同。

## 申请方法

在头像装饰申请页面填写以下内容进行申请:

- 装饰图片
- 名称
- 说明
- 分类

申请将保持待审核状态,直至被驳回或批准。一经批准,即可立即作为头像装饰使用。若被驳回,将通知驳回理由。如需再次申请,请以新申请的形式重新提交。

## 申请前准备好这些内容会更顺利

预先准备好以下内容,填写申请表单时会更顺利。

```
装饰名称:
说明:
分类:
```

## 申请数量限制

同时可提交的申请(待审核)数量有限制(默认为 3 个)。此外,为防止连续申请,还设有速率限制。

## 申请图片的处理

申请时,您可以选择审核完成后是否删除图片。若勾选此项,无论批准还是驳回,审核完成后云端硬盘文件都会被删除(批准时图片已被复制至装饰本身,因此删除原图片不会影响装饰本身)。
