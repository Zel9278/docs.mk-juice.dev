# 小说编辑器

用于编写[小说标记・小说阅读器](./novel.md)所用正文的编辑器。可从导航菜单打开(`/novel-editor`)。写完的正文可以直接生成 .txt 文件,并带上小说标记发布。

## 作品与草稿

- 每部作品都有各自的标题・正文・目标字数,可以在"作品"中切换,或创建"新作品"。
- 草稿会**自动保存在当前浏览器中**,并与同一浏览器的其他标签页同步。
- 由于保存在浏览器中,不会与其他设备或浏览器共享。清除浏览器数据时草稿也会被删除,重要的作品请通过"保存为 .txt"另行保存。如果超出浏览器的存储容量而无法保存,画面上会显示提示。

## 书写

正文中的写法(注音・着重号等注记、章节标题、分隔、分页、粗体等)会以颜色标示,便于区分。以下写法可以通过按钮输入:

| 按钮 | 输入内容 |
| --- | --- |
| 注音 | 为选中的文字添加注音(以 `[[rb:基底 > 读音]]` 的形式插入) |
| 着重号 | 为选中的文字添加着重号(﹅)・白芝麻着重号(﹆)・圆点着重号(●)・白圆点着重号(○) |
| 装饰 | 将选中的文字设为粗体・斜体・删除线 |
| 缩进 | 将选中的行统一缩进指定的字数 |
| 章节标题 | 插入从此处开始的章节标题(`[chapter:…]`) |
| 分隔 | 在此处分隔章节(`---`) |
| 分页 | 在此处换页(`[newpage]`) |
| 破折号・省略号 | 输入 `――`・`……` |

各写法的详细含义请参阅[小说标记・小说阅读器](./novel.md)。

### 显示与输入设置

- 换行时自动缩进段首
- 自动补全括号
- 将正在书写的行保持在屏幕中央
- 并排显示预览
- 字体・文字大小・行高

开启"专注模式"后,编辑器会全屏显示。"查找与替换"还支持区分大小写・正则表达式・按单词搜索。

## 目录与字数

- 目录中会显示各章节的字数,点击即可跳转到该位置。
- 会显示字数、稿纸换算(400 字稿纸,按每行 20 字、每段换行计算的张数)以及选中范围的字数。字数不包括空格・换行・注音读音・注记等写法。
- 设定"目标字数"后,会显示完成进度。

## 预览

可以用与小说阅读器相同的外观进行预览。宽屏时显示在编辑器旁边,窄屏时在单独的窗口中显示。书写过程中也会实时反映到预览中。

## 发布前检查

"发布前检查"会将需要注意的地方列成清单,在单独的窗口中显示。点击项目即可跳转到编辑器中的对应行。书写过程中结果也会更新,发布时如有需要注意的地方也会提示(也可以通过"仍然发布"直接发布)。主要会指出以下情况:

- 注音的添加方式(《》前没有汉字、包含非汉字的词语没有 `｜`、注音写法错误)
- 括号未闭合,或存在没有对应左括号的右括号
- 未在同一行内闭合的粗体・删除线・着重号注记,以及未闭合的缩进注记
- 小说阅读器不支持的注记(不支持 `［＃改ページ］`,会提示改用 `[newpage]`)
- 不是单独一行的 `[newpage]`、没有内容的章节、第一章没有 `[chapter:…]`
- 只用了一个省略号・破折号、使用了"・・・"、！？后面没有全角空格

## 导入・保存・发布

- **导入**: 将设备或网盘中的 .txt 文件作为新作品打开。编码会自动识别。
- **保存为 .txt**: 将正文保存为 .txt 文件。
- **发布**: 将正文生成 .txt 文件上传到网盘,并带上小说标记附加到发帖表单中。
