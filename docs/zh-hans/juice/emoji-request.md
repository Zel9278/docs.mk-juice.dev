# 表情符号申请

允许普通用户申请添加自定义表情符号的功能。

## 申请方法

在表情符号申请页面填写以下内容进行申请:

- 表情符号图片
- 名称
- 分类
- 许可协议

申请将保持待审核状态,直至被驳回或批准。一经批准,即可立即作为自定义表情符号使用。若被驳回,将通知驳回理由。如需再次申请,请以新申请的形式重新提交。

## 申请前准备好这些内容会更顺利

预先准备好以下内容,填写申请表单时会更顺利。

```
表情符号名称:
分类:
标签(用空格分隔):
许可协议(作者名・使用条件等):
是否属于敏感图片:
是否仅限本地:
```

- 表情符号名称只能使用半角英数字和 `_`(例如 `party_blob`)。选择图片后,系统会根据文件名自动填入候选名称。
- 许可协议方面,若为自制内容请填写"本人制作",若使用了素材,请注明来源及许可协议名称(如 CC BY-SA 4.0)。

## 申请数量限制

同时可提交的申请(待审核)数量有限制(默认为 3 个)。此外,为防止连续申请,还设有速率限制。

## 申请图片的处理

申请时,您可以选择审核完成后是否删除图片。若勾选此项,无论批准还是驳回,审核完成后云端硬盘文件都会被删除(批准时图片已被复制至表情符号,因此删除原图片不会影响表情符号本身)。
