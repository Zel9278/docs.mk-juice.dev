# 媒体时间线

以 PixelFed 风格的网格/轮播形式,集中显示带附件的帖子的专用时间线。仅在管理员从 JUICE 独有功能设置中启用后才可使用(参见[JUICE 独有功能设置](./settings.md))。

## 显示范围

- 显示至少附带一个文件、公开范围为"公开"的帖子。
- 附带多个文件的帖子会以可滑动切换的轮播形式显示。滑动判定同时考虑距离和速度,轻轻一划即可切换,使用鼠标操作时图片左右还会显示切换按钮,切换动画也更快完成。

## 内联播放

带有视频或音频的帖子,无需打开放大显示(灯箱)即可直接在时间线上播放。

- 视频配有专用操作栏,支持循环播放、调整播放速度、画中画、放大显示等功能。
- 音频会显示与灯箱相同的可视化效果(发帖者头像+波形)和控制栏。
- 音量设置在灯箱与媒体时间线的所有内联播放之间共享(保存在本机本地,调整一次后,之后打开任何视频/音频都会保持相同音量)。

## 按帖子排除显示

在发帖表单的"..."菜单中选择"不在媒体时间线中显示",即可将该帖子从媒体时间线中排除。适用于美食照片等不希望出现在媒体时间线中的帖子。

该设置仅影响媒体时间线,不会影响主页、本地等常规时间线,也不会影响个人资料的"文件"标签页、搜索结果等其他文件筛选显示。

## 标签的显示与隐藏

是否在时间线页面的标签栏中显示媒体时间线标签,可以在 `/settings/juice` 中按每位用户单独切换。详情请参见[JUICE 独有功能设置](./settings.md)。

## 在Deck中使用

在Deck UI中添加或编辑"时间线"栏目时,类型选择中也可以选择媒体时间线。作为来源的时间线(主页/本地/混合/全局)可以按每个栏目单独设置。
