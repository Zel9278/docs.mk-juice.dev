# 小说标记・小说阅读器

可为帖子添加"小说"标记,并在专用的小说阅读器中阅读。阅读器支持竖排的文库本风格显示,以及注音・着重号等[青空文库](https://www.aozora.gr.jp/)标记和 pixiv 小说标记。

## 以小说形式发帖

### 添加小说标记

- **发帖表单**: 点击下方工具栏中的书本图标(位于 AI 生成内容按钮旁)将其开启。
- **发帖之后**: 在自己帖子的"…"菜单中选择"标记为小说"/"取消小说标记",即可随时添加或取消。
- **Drive 中的 .txt 文件**: 在 Drive 中打开 .txt 文件的菜单,选择"标记为小说"。将带标记的文件附加到帖子时,帖子也会自动带上小说标记(也可以手动取消)。

带有小说标记的帖子会有以下表现:

- 在时间线和帖子详情中,名字旁边会显示书本徽章。点击徽章即可在小说阅读器中打开。
- 也可以通过"…"菜单中的"以小说模式阅读"打开小说阅读器。
- 即使没有附件,也会显示在[媒体时间线](./media-timeline.md)中。
- 可以通过普通时间线(首页・本地・社交・全局)菜单中的"仅显示小说"进行筛选。

### 正文放在哪里

- **短篇**: 直接写在帖子正文中。
- **长篇**: 将正文保存为 .txt 文件并附加。这样也能阅读超过帖子字数上限的长篇。
  - 编码支持 UTF-8・Shift_JIS・EUC-JP(自动识别)。
  - 附加了 .txt 文件时,会显示 .txt 文件的内容作为小说,而不是帖子正文。
  - 附加了多个 .txt 文件时,优先使用在 Drive 中添加了小说标记的文件。
- **使用[小说编辑器](./novel-editor.md)书写**: 可以借助写法输入辅助・预览・发布前检查进行书写。写完的正文可以生成 .txt 文件,并带上小说标记发布。

## 正文中可用的写法

小说阅读器会以 **原样的文字** 显示正文。MFM(链接・提及・话题标签・自定义表情符号・`$[…]` 函数・`<center>` 等)不会被解析,会直接以文字显示。在此基础上,只有以下小说中常用的写法会生效。

### 章节与分页

| 写法 | 含义 |
| --- | --- |
| `---`(单独一行,三个及以上连字符) | 章节分隔。会作为章节列在目录中,横排时每个章节都会显示"上一章""目录""下一章" |
| `[newpage]`(单独一行) | 分页(与 pixiv 小说相同)。横排时每次显示一页,通过"上一页"/"下一页"切换;竖排时从这里开始必定进入下一页 |
| `[chapter:标题]` | 章节标题。在正文中作为标题显示,目录中也会以此名称列出(没有标题的章节显示为"第N章") |

```text
[chapter:一　开始]
正文……

---

[chapter:二　继续]
正文……

[newpage]

[chapter:三　下一页的章节]
正文……
```

::: tip
如果第一章也加上 `[chapter:…]`,目录中就会显示章节名,而不是"第1章"。
:::

### 注音(ruby)

| 写法 | 示例 |
| --- | --- |
| `｜基底《读音》`(青空文库) | `｜潮待ち便《しおまちびん》` |
| `汉字《读音》`(省略 ｜) | `潮見島《しおみじま》` |
| `＊基底《读音》`・`*基底《读音》`・`\|基底《读音》` | `＊御立会《おたちあい》` |
| `[[rb:基底 > 读音]]`(pixiv) | `[[rb:灯台守 > とうだいもり]]` |
| `$[ruby 基底 读音]`(MFM) | `$[ruby 真鍮 しんちゅう]` |

::: warning
省略 `｜` 等标记时,注音 **只会加在《》紧挨在前的连续汉字上**(青空文库的规则)。例如 `潮待ち便《しおまちびん》` 中汉字在"ち"处中断,因此只有"便"会加上注音。为包含非汉字的词语加注音时,请务必像 `｜潮待ち便《しおまちびん》` 这样标明起始位置。
:::

### 着重号(青空文库)

| 写法 | 示例 |
| --- | --- |
| `［＃「对象」に傍点］` | `潮待ち便［＃「潮待ち便」に傍点］` |
| `［＃傍点］…［＃傍点終わり］` | `［＃傍点］ここだけ［＃傍点終わり］` |

- 青空文库的正式写法是将对象文字放在注记的 **紧前方**(放在紧后方也会生效)。
- 除 `傍点`(黑芝麻点)外,还可以使用 `白ゴマ傍点`(白芝麻点)・`丸傍点`(黑圆点)・`白丸傍点`(白圆点)。
- 竖排时显示在文字右侧,横排时显示在上方。

### 缩进(青空文库)

```text
［＃ここから2字下げ］
需要缩进的行
需要缩进的行
［＃ここで字下げ終わり］
```

区块内每一行的开头会按数字插入相应数量的全角空格。

### 文字装饰

| 写法 | 显示 |
| --- | --- |
| `**粗体**` | **粗体** |
| `*斜体*` | *斜体* |
| `~~删除线~~` | ~~删除线~~ |

- 可以嵌套(例: `**粗体中的~~删除线~~**`)。装饰中也可以加入注音。
- **只有在同一行内闭合时** 才会生效。跨越换行时会直接显示符号。
- 像 `* 注` 这样,符号紧后方(或紧前方)是空格时,会被视为普通符号而非装饰。

### 其他 pixiv 小说写法

| 写法 | 显示 |
| --- | --- |
| `[[jumpuri:显示名称 > URL]]` | 只显示名称文字(不会添加链接) |
| `[jump:N]` | 不显示 |
| `[pixivimage:…]` | 不显示 |

### 关于青空文库格式的文本

- 开头的"【テキスト中に現れる記号について】"凡例块(由横线包围的部分)会被自动移除。
- 此处未列出的 `［＃…］` 注记(不支持的注记)会连同注记一起从显示中消失。

如果读者在显示设置中关闭了"解析青空文库标记",《》注音・着重号・缩进注记将不会被解析,而是直接以文字显示(默认开启)。

### 自动缩进

读者的显示设置"段落缩进"开启时(默认),行首没有空格的行会自动缩进一个全角空格。以下列字符开头的行不会缩进:

- 已经以空格(全角・半角)开头的行
- 左括号: `「 『 （ ( 〔 ［ [ ｛ { 〈 《 【 〘 〖 ｢ “ ‘`
- 符号: `・ ･ ― — ﹅ ﹆ ● ○ ◎ ◯ ◆ ◇ ■ □ ★ ☆ ※ 、 。 ，`

这是为了防止对话(「」)和场景切换符号(◆・＊・●○ 等)的行被擅自缩进。另外,以注音写法 `[[rb:…]]` 开头的行会作为普通文字行进行缩进。

### 竖排时的显示

- 英文字母・数字会逐个竖立排列。
- `…` `‥` `―` `—` 以及半角的 `( ) [ ] { } < > - ~ =` 等,会为竖排旋转 90 度显示。
- 当注音跨越页面边界时,会在其前方分页以免被截断(因此每页的宽度可能略有不同)。

### 发帖前检查清单

- 已添加小说标记(或已附加带小说标记的 .txt 文件)
- 包含非汉字的词语的注音已用 `｜` 标明起始位置
- 如需在目录中显示章节名,第一章也已加上 `[chapter:…]`
- 粗体等装饰已在同一行内闭合
- 长篇已作为 .txt 文件附加

## 在小说阅读器中阅读

- **横排/竖排**: 可以切换。竖排是像文库本一样从右向左翻页的显示方式,屏幕足够宽时会以跨页(两页)形式显示。
- **翻页方式**(竖排): 除页面下方的按钮外,还可以滑动(向右滑动为下一页)或使用键盘的 ←(下一页)/→(上一页)翻页。
- **全屏阅读**: 只将正文铺满整个屏幕显示。全屏状态下也可以打开目录・显示设置,并切换横排/竖排。
- **显示设置**: 可以更改文字大小、字体(标准・明朝体・黑体)、背景(自动・白・棕褐・黑・自定义)、段落缩进、青空文库标记的解析。设置按设备保存。
- **书签**: 会记住竖排时阅读到的页面,下次打开时从该处继续(按设备保存,最多最近 50 部作品)。
- **字数与阅读时间估算**: 显示在作者名下方。不计算空格・换行・注音读音,按每分钟约 500 字计算。
- 即使改变窗口大小,也会在保持阅读位置的同时重新分页。

## 在其他服务器上的显示

小说标记会作为 Juice Server 独有的 ActivityPub 属性发送给联合的服务器。JUICE 之间会以小说形式联合,不支持的服务器会直接忽略。

- 如果管理员开启了"小说帖子的CW回退"(控制面板的 JUICE 设置,默认关闭),在非 JUICE 服务器上会带有写着"小说"的 CW 显示。其机制与 [AI 生成内容标记](./ai-generated-flag.md)的 CW 回退相同,同时符合两者的帖子以 AI 生成内容为优先。
- 在非 JUICE 服务器上,正文会作为普通帖子显示,因此 `［＃…］` 和 `[newpage]` 等写法会直接以文字显示。
