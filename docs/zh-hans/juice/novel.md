# 小说标记・小说阅读器

可为帖子添加"小说"标记,并在专用的小说阅读器中阅读。阅读器支持竖排的文库本风格显示,以及注音(ruby)和[青空文库](https://www.aozora.gr.jp/)标记。

## 添加小说标记

- 在发帖表单中,打开 AI 生成内容标记开关旁的"标记为小说"后发帖。
- 发帖后,也可以在帖子的"…"菜单中通过"标记为小说"/"取消小说标记"切换。
- 带有标记的帖子会显示书本徽章。

### 以 .txt 文件发布长篇

超过帖子正文字数上限的长篇,可将正文作为 .txt 文件附加,小说阅读器会将该文件作为正文读取。

- 支持 UTF-8 和 Shift_JIS 编码(自动识别)。
- 也可以为 Drive 中的 .txt 文件添加小说标记。将带标记的文件附加到帖子时,帖子也会自动带上小说标记。
- 附加了多个 .txt 文件时,优先使用带小说标记的文件。

## 在小说阅读器中阅读

带标记的帖子可通过书本徽章,或帖子"…"菜单中的"以小说模式阅读"在小说阅读器中打开(`/notes/<帖子ID>/novel-viewer`)。

### 横排与竖排

- **横排**: 普通的滚动显示。每个章节的分界处会显示目录以及前后章节的链接。
- **竖排**: 像文库本一样从右向左翻页的显示方式。屏幕足够宽时会以跨页(两页)形式显示。

### 章节与目录

正文中单独一行的 `---`(三个及以上连字符)会作为章节分隔。没有分隔时,全文视为一个章节。可以通过目录跳转章节。

### 显示设置

可在阅读器的"显示设置"中更改以下内容。设置按设备保存。

- 文字大小(小・标准・大・特大)
- 字体(标准・明朝体・黑体)
- 背景(自动・白・棕褐・黑・自定义)。自定义时可自由选择文字颜色和背景颜色
- 段落缩进: 自动为行首没有全角空格的段落补上缩进。已经缩进的段落保持不变
- 解析青空文库标记: 支持以下标记
  - 注音: `｜漢字《かんじ》` 或 `漢字《かんじ》`(紧挨在前的连续汉字会成为注音对象)
  - 缩进: `［＃ここから2字下げ］`～`［＃ここで字下げ終わり］`
  - 开头的"テキスト中に現れる記号について"凡例块会从正文中移除
  - 不支持的标记不会显示

### 书签

竖排模式下阅读到的页面会被自动记住,下次打开时可以接着阅读(按设备保存,最多最近 50 部作品)。

## 在时间线中的显示

- 在普通时间线(首页・本地・社交・全局)的菜单中选择"仅显示小说",即可只显示带小说标记的帖子。
- 带小说标记的帖子即使没有附件,也会显示在[媒体时间线](./media-timeline.md)中。

## 与其他实例的联合

小说标记会作为 Juice Server 独有的 ActivityPub 属性发送给联合的实例。不支持的实例会直接忽略。

针对无法解析该属性的非 JUICE 实例,还提供了在联合时以 CW 形式发送小说信息的回退设置(控制面板的 JUICE 设置,默认关闭)。其机制与 [AI 生成内容标记](./ai-generated-flag.md)的 CW 回退相同,同时符合两者的帖子以 AI 生成内容为优先。
