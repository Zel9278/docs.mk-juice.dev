# 关于本服务器的运营方针

## 什么是 Juice Server?

Juice Server 是追踪 Misskey 非官方分支 [misskey-juice](https://github.com/Zel9278/misskey-juice) 的 [`juice/main` 分支](https://github.com/Zel9278/misskey-juice/tree/juice/main) 的官方服务器。

## 作为测试服务器的定位

Juice Server 是为了在实际运营环境中验证 misskey-juice 开发的新功能和修复而构建和运营的。

- **目前启用审核制注册正是出于这一验证目的。** 这不是任何人都可以自由注册的服务器,而是需要审核注册申请内容后才能通过的方式。
- 有时会提前启用 misskey-juice 中仍在验证阶段的功能,可能会出现意外问题。
- 如果您发现问题,请通过 Misskey 消息联系管理员([@c30](https://mk-juice.dev/@c30)),这将对我们有很大帮助。

## 作为通用服务器的运营

除了上述测试目的外,**我们还计划将本服务器作为面向创作者以及希望与他人正常交流的用户的通用服务器来运营。**

使用前请务必阅读以下内容。

- [规则](./service/rules.md)
- [服务条款](./service/tos.md)

## 关于数据处理

- 数据库会定期自动备份,并加密后存储在外部存储中。
- 但由于本服务器属于测试服务器性质,不能完全排除因验证中的问题导致数据丢失的可能性。敬请谅解。

## 联系方式

如有疑问、需求或错误反馈,请通过 Misskey 消息联系管理员([@c30](https://mk-juice.dev/@c30))。
