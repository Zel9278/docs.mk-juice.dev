# 服务条款

在使用由 c30(ced)运营的分布式微博客 SNS Misskey 非官方分支「misskey-juice」的官方实例「Juice Server」(以下简称"本服务")时,请遵守以下规则,文明使用本服务。
若确认存在违规行为,我们可能会限制您对服务或账号的使用。
本条款内容可能在不另行通知用户的情况下进行变更。

## 关于本实例

本实例是包括 [Mastodon](https://joinmastodon.org/)、[Misskey](https://misskey-hub.net/)、[Pleroma](https://pleroma.social/) 等软件在内的分布式微博客 SNS 网络的一部分。

本实例使用的是 [Misskey](https://misskey-hub.net/) 的分支 [misskey-juice](https://github.com/Zel9278/misskey-juice)。

## 免责声明

- 本服务是使用名为"ActivityPub"的机制的分布式 SNS,发帖的瞬间即会向全球联合的实例发送并复制,因此一旦发布的信息可能难以彻底删除。
- 本服务面向日本国内用户提供,服务条款等适用法律以日本法律为准据法。
- 隐私保护方针基于日本个人信息保护法制定。
- 出于对儿童安全和隐私的保护,禁止未满 13 周岁人士使用本服务,以及未成年人向实例发送真实姓名、照片等可识别个人身份的信息。
- 出于本服务内容的性质,请未满 16 周岁人士自觉避免注册。
- 我方对用户之间因使用本服务产生的任何纠纷或损失,概不承担任何责任。

## 禁止行为

符合以下项目的行为将导致账号封禁及删除:

- 故意对服务器造成负担的行为
- 向实例发送违反法律内容的行为
- 以买卖为目的获取账号及买卖账号
- 使用一次性邮箱地址创建账号
- 为非法网站、成人网站等进行宣传的行为
- 账号创建后立即诱导前往非常规购物网站的行为
- 账号创建后立即在个人资料中填写公司信息的行为
- 未添加敏感内容警示标记发布露骨性内容的媒体
- 未满 13 周岁使用本服务
- 未成年人向实例发送真实姓名、照片等可识别个人身份的信息
- 发布与日本国内管制药物等相关话题的内容

以及其他被认为不适当的行为

符合以下项目的行为将导致账号被沉默:
沉默状态下,公开范围将无法选择"公开"。

- 攻击性或恶意的过激言论
- 通过 MFM 文字装饰或字符画等方式发布露骨性内容的帖子
- 未添加 CW 转发符合上述任一情况的内容

以及其他被认为不适当的行为

## 关于机器人运营

符合以下项目的机器人,其开发者有义务采取相应对策。
此外,所有机器人管理员均需定期检查机器人发布的内容。

若未采取以下对策且发生滥用情况,可能会封禁机器人账号。

- 利用搜索引擎等根据关键词自动发布图片的机器人
  - 请设置过滤及 NSFW 标记以避免显示不适当的图片
- 具备根据用户操作进行回复或公开发帖功能的机器人
  - 请设置速率限制以避免大量发帖
  - 请设置过滤以避免对不适当词语作出反应

## 关于信息收集

为运营本服务,本服务将收集以下信息:

- 电子邮箱地址(如已设置)
- IP 地址
- 其他[隐私政策](./privacy_policy.md)中记载的信息

所收集的信息仅限于以下目的使用,不用于其他目的:

- 用于邮件通知功能等本服务的提供
- 用于警告违反服务条款的用户或封禁账号
- 用于提升服务体验

除法律要求外,我方不会将这些信息透露给第三方。
同时,我方也不会将信息处理事务委托给外部机构。

## 关于账号关闭与数据删除

本服务是使用名为 ActivityPub 机制的分布式 SNS,帖子及个人资料等信息会自动发送并复制到联合实例。因此,即使在本服务中删除账号或帖子,该删除操作也不一定会立即反映到联合的其他实例上;对于删除请求应对方针不同的实例,或已停止运营的实例,已复制的数据可能会继续留存。

您可以通过本服务的功能自行完成账号关闭(注销)或个别帖子・文件的删除。但基于上述特性,对于我方无法掌握・管理的外部实例上留存的数据,我方无法保证可以删除,且不承担任何责任。
