# 隐私政策

## 关于本服务器的隐私保护

c30(ced)(以下简称"我方")运营及管理的分布式微博客 SNS 服务「Juice Server」(以下简称"本服务")就其隐私信息的处理方式,制定如下隐私政策(以下简称"本政策")。

## 本服务收集的个人信息

### 第一条(隐私信息的定义)

1. 隐私信息中的"个人信息"指个人信息保护法所规定的"个人信息",即关于在世个人的信息,包含出生日期、住址、电话号码或其他可识别特定个人的记述等信息。
2. 隐私信息中的"历史信息及特征信息"指上述"个人信息"以外的信息,包括用户浏览的网页、搜索的关键词、使用日期时间、使用方法、使用环境、年龄、用户 IP 地址、Cookie 信息、位置信息、终端设备识别信息等。

### 第二条(隐私信息的收集方法)

1. 本服务在用户进行使用登记时,可能会询问电子邮箱地址等个人信息。
2. 除上述内容外,在确认是否满足本服务服务条款规定的年龄要求时,可能会询问出生日期等额外的个人信息。
3. 本服务会在用户使用、浏览本服务时,收集用户的历史信息及特征信息(通过智能手机等移动终端使用时,也包括该终端的通信状态、使用时的各项设置信息等)。

### 第三条(收集及使用个人信息的目的)

本服务收集及使用个人信息的目的如下:

1. 为使用户能够查看或修改自己的注册信息、查看使用情况,而显示注册信息、所使用服务等相关信息的目的
2. 为进行用户身份确认,而使用电子邮箱地址等联系方式信息的目的
3. 为向用户告知或联系有关本服务的事项,而使用电子邮箱地址的目的
4. 为使用户能够便捷地输入数据,根据用户的指示将本服务中注册的信息转发等操作到其他服务器的目的
5. 为应对用户的咨询,而使用咨询内容、本服务向用户提供服务所需的信息、用户的服务使用情况、联系方式信息等的目的
6. 附随于上述使用目的的目的

### 第四条(向第三方提供个人信息)

1. 除以下情况外,本服务不会在未事先获得用户同意的情况下向第三方提供个人信息。\
   但个人信息保护法及其他法令所允许的情况,或作为用户公开信息注册的出生日期,不在此限。
   1. 基于法令规定的情况
   2. 为保护人的生命、身体或财产而有必要,且难以获得本人同意的情况
   3. 为提升公共卫生或促进儿童健康成长而特别有必要,且难以获得本人同意的情况
   4. 国家机关、地方公共团体或受其委托的第三方机构为执行法令所规定事务需要协助的情况下,若获得本人同意可能妨碍该事务执行的情况
   5. 事先已告知或公布以下内容的情况:
      1. 使用目的中包含向第三方提供
      2. 向第三方提供的数据项目
      3. 向第三方提供的手段或方法
2. 尽管有上述规定,以下情况不视为第三方:
   1. 包括版主在内的本服务运营成员
   2. 在实现本服务使用目的所需的范围内,委托个人信息处理的部分或全部的情况
   3. 因合并或其他事由导致业务继承而提供个人信息的情况
   4. 与特定方共同使用个人信息的情况下,已事先将该情况及共同使用的个人信息项目、共同使用者的范围、共同使用者使用个人信息的目的以及对该个人信息管理负责人的姓名或名称通知本人,或使本人能够容易知悉的情况

### 第五条(个人信息的披露)

本服务在本人提出个人信息披露请求时,将及时向本人披露相关信息。\
但若披露符合以下任一情形,可能不披露全部或部分内容。若决定不披露,将及时告知本人相关情况。\
此外,披露个人信息时,每次将收取 1,500 日元的手续费。

1. 可能损害本人或第三方的生命、身体、财产或其他权益的情况
2. 可能对本服务运营的正常实施造成显著妨碍的情况
3. 其他违反法令的情况
4. 尽管有上述规定,原则上不披露历史信息及特征信息等以外的个人信息以外的信息。

### 第六条(个人信息的更正或删除)

1. 若用户认为本服务持有的自身个人信息有误,除以下情况外,可依照本服务规定的程序要求本服务更正个人信息。
   1. 因违规行为等原因导致账号处于封禁状态的情况
   2. 我方认为不适当的情况
   3. 技术上无法实现的情况
2. 本服务在收到用户上述请求后,若认为有必要回应该请求,将及时更正相关个人信息,并将此告知用户。

### 第七条(本政策的变更)

1. 本政策内容可能在不另行通知用户的情况下进行变更。
2. 除本服务另行规定外,修订后的本政策自[本网站](https://docs.mk-juice.dev/)刊登之时起生效。
