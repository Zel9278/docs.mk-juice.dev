# 投稿言語

投稿ごとに言語を明示的に指定できる機能です。Mastodonと互換性のある形式で連合します。

## 投稿時の言語指定

投稿フォームで、投稿の言語(BCP 47言語タグ)を明示的に指定できます。指定しない場合は、表示言語の設定が既定値として使われます。

ActivityPubでの連合には、AS2標準の`contentMap`を使用します(Mastodon・Akkoma互換)。

## タイムラインの言語フィルター

JUICE独自機能の設定から、ホーム・ローカル・グローバルタイムラインへ表示する投稿を言語で絞り込めます。Mastodonの「フィルタする言語」を参考にした機能ですが、以下の点が異なります。

- 全てのタイムラインに適用されます。
- リノートも、リノート元ノートの言語で判定します。
- 言語が指定されていない投稿・自分自身の投稿は、設定に関わらず常に表示されます。

タイムライン画面の「…」メニューからも直接切り替えられます。

## 検索での言語指定

ノート検索・リアクション検索の高度な検索オプションに、投稿の言語での絞り込みがあります。

## ローカルユーザーのみ表示

ホームタイムラインの「…」メニューに、ローカルユーザーの投稿だけに絞り込む切り替えがあります。フォロー中のリモートユーザーの投稿を一時的に非表示にしたい場合にご利用ください。
