# 連携ログイン

Discord・Google・GitHub・GitLab・Microsoftのアカウントと連携し、それらのアカウントでのサインインを利用できる機能です。

## 連携の設定

設定の「JUICE」ページ(「アカウント」カテゴリ)から、各サービスのアカウントを連携・解除できます。連携するだけでなく、サインイン手段として使うかどうかも個別に切り替えられます。

サインイン手段として有効にしている場合、サインイン画面に対応するプロバイダーのボタンが表示され、そこから連携先のアカウントでログインできるようになります。

## 安全のための制約

連携ログインをサインイン手段として使うには、次の条件を両方満たす必要があります。

- **自分のMisskeyアカウントで二要素認証(2FA)を有効にしていること**
- **サインイン手段として使うことを個別にオプトインしていること**(連携するだけでは自動的にサインイン手段にはなりません)

これは、連携先アカウント(例: Google)が乗っ取られただけで、そのままMisskeyアカウントに侵入されてしまうことを防ぐための制約です。本家Misskeyがかつて同種の機能を廃止した理由への対策として、サーバー側で強制されています。

## 対応プロバイダー

- Discord
- Google
- GitHub
- GitLab
- Microsoft

各プロバイダーは、管理者がコントロールパネルのJUICE設定で有効化しているものだけ利用できます。
