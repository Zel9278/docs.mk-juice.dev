# 絵文字申請

一般ユーザーがカスタム絵文字の追加を申請できる機能です。

## 申請方法

絵文字申請ページから、以下の項目を入力して申請します。

- 絵文字画像
- 名前
- カテゴリ
- ライセンス

申請は却下または承認されるまで保持されます。承認されると、そのままカスタム絵文字として利用できるようになります。却下された場合は理由が通知されます。もう一度申請したい場合は、新しい申請として出し直してください。

## 申請前に準備しておくと良い項目

以下のような内容をあらかじめ用意しておくと、フォームへの入力がスムーズです。

```
絵文字名:
カテゴリ:
タグ(スペース区切り):
ライセンス(作者名・利用条件など):
センシティブ画像に該当するか:
ローカル限定にするか:
```

- 絵文字名には半角英数字と `_` のみ使用できます(例: `party_blob`)。画像を選択すると、ファイル名から自動で候補が入力されます。
- ライセンスは、自作なら「本人作成」、素材を利用した場合は配布元やライセンス名(CC BY-SA 4.0 など)を明記してください。

## 申請数の上限

同時に出せる申請(審査待ち)の件数には上限があります(既定3件)。また、連続申請を防ぐためのレート制限もあります。

## 申請画像の扱い

申請時に、審査完了後に画像を削除するかどうかを選択できます。チェックを入れた場合、承認・却下いずれの場合も審査完了時にDriveファイルが削除されます(承認時は絵文字側に画像がコピーされるため、削除しても絵文字自体には影響ありません)。
