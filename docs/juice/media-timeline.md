# メディアタイムライン

添付ファイル付きのノートだけを、PixelFed風のグリッド/カルーセル表示で集めた専用タイムラインです。管理者がJUICE独自機能の設定から有効にした場合のみ利用できます([JUICE独自機能の設定](./settings.md)を参照)。

## 表示される投稿

- 1枚以上ファイルが添付された、公開範囲が「公開」のノートが対象です。
- 複数枚添付されている投稿は、スワイプで送れるカルーセル表示になります。スワイプの判定は距離・速度の両方で行われるため軽く弾くだけでも送れ、マウス操作時は画像の左右に送りボタンも表示されます。切り替えアニメーションも短時間で完了します。

## インライン再生

動画・音声が添付された投稿は、拡大表示(ライトボックス)を開かなくても、タイムライン上でその場で再生できます。

- 動画には、ループ再生・再生速度変更・ピクチャインピクチャ・拡大表示といった専用の操作バーが付きます。
- 音声には、ライトボックスと同じビジュアライザー(投稿者アバター+波形)とコントロールバーが表示されます。
- 音量設定は、ライトボックスとメディアタイムラインのインライン再生全体で共有されます(端末ローカルに保存されるため、一度調整すれば以後どの動画・音声を開いても同じ音量になります)。

## 投稿ごとの表示除外

投稿フォームの「…」から「メディアタイムラインに表示しない」を選ぶと、その投稿だけをメディアタイムラインの対象から除外できます。飯テロ画像など、メディアタイムラインには出したくない投稿がある場合にご利用ください。

この設定はメディアタイムラインにのみ効きます。ホーム・ローカルなど通常のタイムラインや、プロフィールの「ファイル」タブ、検索結果など他のファイル絞り込み表示には影響しません。

## タブの表示・非表示

タイムライン画面のタブバーにメディアタイムラインのタブを表示するかどうかは、閲覧者ごとに`/settings/juice`から個別に切り替えられます。詳しくは[JUICE独自機能の設定](./settings.md)を参照してください。

## デッキでの利用

デッキUIの「タイムライン」カラムを追加・編集する際の種別選択からもメディアタイムラインを選べます。表示対象のタイムライン(ホーム/ローカル/ハイブリッド/グローバル)はカラムごとに個別に設定できます。
