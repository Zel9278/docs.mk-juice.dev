# 小説フラグ・小説ビューワー

投稿に「小説」フラグを付けて、専用の小説ビューワーで読めるようにする機能です。縦書きの文庫本風表示や、ルビ・傍点などの[青空文庫](https://www.aozora.gr.jp/)記法、pixiv小説の記法にも対応しています。

## 小説として投稿する

### 小説フラグを付ける

- **投稿フォーム**: 下のツールバーにある本のアイコン(AI生成物フラグのボタンの隣)を押してオンにします。
- **投稿したあと**: 自分のノートの「…」メニュー →「小説としてマーク」/「小説のマークを解除」で、あとから付け外しできます。
- **ドライブの.txtファイル**: ドライブで.txtファイルのメニュー →「小説としてマーク」。フラグを付けたファイルを投稿に添付すると、投稿にも自動で小説フラグが付きます(手動で外すこともできます)。

小説フラグが付いた投稿は、次のように扱われます。

- タイムラインやノート詳細で、名前の横に本のバッジが付きます。バッジを押すと小説ビューワーで開きます。
- 「…」メニューの「小説として読む」からも小説ビューワーを開けます。
- 添付ファイルが無くても[メディアタイムライン](./media-timeline.md)に表示されます。
- 通常のタイムライン(ホーム・ローカル・ソーシャル・グローバル)のメニューにある「小説のみ表示」で絞り込めます。

### 本文の置き場所

- **短いもの**: ノートの本文にそのまま書きます。
- **長いもの**: 本文を.txtファイルにして添付します。ノートの文字数上限を超える長編も読めます。
  - 文字コードはUTF-8・Shift_JIS・EUC-JPのどれでも構いません(自動で判別します)。
  - .txtファイルが添付されていれば、ノートの本文ではなく.txtファイルの中身が小説として表示されます。
  - .txtファイルが複数添付されている場合は、ドライブで小説フラグを付けたファイルが優先されます。

## 本文で使える書き方

小説ビューワーは、本文を**書いたままの文字**で表示します。MFM(リンク・メンション・ハッシュタグ・カスタム絵文字・`$[…]`の関数・`<center>`など)は解釈されず、そのまま文字として表示されます。そのうえで、小説でよく使う次の書き方だけが反映されます。

### 章と改ページ

| 書き方 | 意味 |
| --- | --- |
| `---`(独立した行、3つ以上のハイフン) | 章の区切り。目次に章として並び、横書きでは章ごとに「前の章」「目次」「次の章」が表示されます |
| `[newpage]`(独立した行) | 改ページ(pixiv小説と同じ)。横書きでは1ページずつ表示して「前のページ」「次のページ」で移動し、縦書きではここから必ず次のページになります |
| `[chapter:タイトル]` | 章のタイトル。本文ではタイトルとして表示され、目次にもこの名前で並びます(無い章は「第N章」) |

```text
[chapter:一　はじまり]
本文……

---

[chapter:二　つづき]
本文……

[newpage]

[chapter:三　次のページの章]
本文……
```

::: tip
1章目にも`[chapter:…]`を付けておくと、目次に「第1章」ではなく章名が表示されます。
:::

### ルビ(ふりがな)

| 書き方 | 例 |
| --- | --- |
| `｜基底《よみ》`(青空文庫) | `｜潮待ち便《しおまちびん》` |
| `漢字《よみ》`(｜を省略) | `潮見島《しおみじま》` |
| `＊基底《よみ》`・`*基底《よみ》`・`\|基底《よみ》` | `＊御立会《おたちあい》` |
| `[[rb:基底 > よみ]]`(pixiv) | `[[rb:灯台守 > とうだいもり]]` |
| `$[ruby 基底 よみ]`(MFM) | `$[ruby 真鍮 しんちゅう]` |

::: warning
`｜`などの印を省略した場合、ルビが付くのは《》の**直前に続いている漢字だけ**です(青空文庫の決まり)。たとえば`潮待ち便《しおまちびん》`は「ち」で漢字が途切れるので、「便」だけにルビが付きます。漢字以外を含む語にルビを振るときは、必ず`｜潮待ち便《しおまちびん》`のように始まりを示してください。
:::

### 傍点(青空文庫)

| 書き方 | 例 |
| --- | --- |
| `［＃「対象」に傍点］` | `潮待ち便［＃「潮待ち便」に傍点］` |
| `［＃傍点］…［＃傍点終わり］` | `［＃傍点］ここだけ［＃傍点終わり］` |

- 対象の文字列は、注記の**直前**に置くのが青空文庫の正式な書き方です(直後に置いても反映されます)。
- `傍点`(黒ゴマ)のほか、`白ゴマ傍点`・`丸傍点`・`白丸傍点`も使えます。
- 縦書きでは文字の右側、横書きでは上側に付きます。

### 字下げ(青空文庫)

```text
［＃ここから2字下げ］
字下げしたい行
字下げしたい行
［＃ここで字下げ終わり］
```

数字の分だけ、ブロック内の各行の先頭に全角スペースが入ります。

### 文字の装飾

| 書き方 | 表示 |
| --- | --- |
| `**太字**` | **太字** |
| `*斜体*` | *斜体* |
| `~~打ち消し線~~` | ~~打ち消し線~~ |

- 入れ子にできます(例: `**太字の中の~~打ち消し~~**`)。装飾の中にルビを入れても構いません。
- **1行の中で閉じているときだけ**反映されます。改行をまたぐと記号のまま表示されます。
- `* 注`のように、記号のすぐ後ろ(または前)が空白の場合は、装飾ではなくただの記号として扱われます。

### その他のpixiv小説の記法

| 書き方 | 表示 |
| --- | --- |
| `[[jumpuri:表示名 > URL]]` | 表示名の文字だけ(リンクは張られません) |
| `[jump:N]` | 表示されません |
| `[pixivimage:…]` | 表示されません |

### 青空文庫形式のテキストについて

- 冒頭の「【テキスト中に現れる記号について】」の凡例ブロック(罫線で挟まれた部分)は、自動で取り除かれます。
- ここで挙げた以外の`［＃…］`の注記(未対応のもの)は、注記ごと表示から消えます。

読者が表示設定で「青空文庫記法を解釈する」をオフにしている場合、《》のルビ・傍点・字下げの注記は解釈されず、そのまま文字として表示されます(既定はオン)。

### 自動の字下げ

読者の表示設定「段落の字下げ」がオン(既定)のとき、行頭にスペースが無い行には、自動で全角スペース1つ分の字下げが入ります。次の文字で始まる行は字下げされません。

- 既にスペース(全角・半角)で始まっている行
- 始め括弧: `「 『 （ ( 〔 ［ [ ｛ { 〈 《 【 〘 〖 ｢ “ ‘`
- 記号: `・ ･ ― — ﹅ ﹆ ● ○ ◎ ◯ ◆ ◇ ■ □ ★ ☆ ※ 、 。 ，`

会話文(「」)や、場面転換の記号(◆・＊・●○など)の行が勝手に下がらないようにするためです。なお、ルビ記法`[[rb:…]]`で始まる行は、普通の文章の行として字下げされます。

### 縦書きでの表示

- 英字・数字は1文字ずつ立てて縦に並びます。
- `…` `‥` `―` `—`や、半角の`( ) [ ] { } < > - ~ =`などは、縦書き用に90度回して表示されます。
- ルビがページの境目にかかる場合は、見切れないようにその手前でページが区切られます(そのため、ページごとに幅が少し変わることがあります)。

### 投稿前のチェックリスト

- 小説フラグを付けた(または小説フラグ付きの.txtファイルを添付した)
- 漢字以外を含む語のルビは、`｜`で始まりを示した
- 目次に章名を出したい場合、1章目にも`[chapter:…]`を付けた
- 太字などの装飾は、1行の中で閉じている
- 長編は.txtファイルで添付した

## 小説ビューワーで読む

- **横書き/縦書き**: 切り替えられます。縦書きは文庫本のように右から左へページをめくる表示で、画面が十分に広いと見開き(2ページ)表示になります。
- **ページのめくり方**(縦書き): ページ下のボタンのほか、スワイプ(右へ動かすと次のページ)や、キーボードの←(次のページ)/→(前のページ)でもめくれます。
- **全画面表示**: 本文だけを画面いっぱいに表示します。全画面のままでも、目次・表示設定・縦書き/横書きの切り替えができます。
- **表示設定**: 文字サイズ、書体(標準・明朝体・ゴシック体)、背景(自動・白・セピア・黒・カスタム)、段落の字下げ、青空文庫記法の解釈を変更できます。設定は端末ごとに保存されます。
- **しおり**: 縦書きで読んでいたページを覚えていて、次に開いたときにそこから再開します(端末ごとに、直近50作品まで)。
- **文字数と読了時間の目安**: 作者名の下に「N文字・約N分で読めます」と表示されます。空白・改行・ルビのよみは数えず、1分あたり約500文字で計算しています。
- ウインドウの大きさを変えても、読んでいた位置を保ったままページが区切り直されます。

## 他のサーバーでの見え方

小説フラグは、Juice Server独自のActivityPubプロパティとして連合先にも送信されます。JUICE同士では小説として連合し、対応していないサーバーからは単に無視されます。

- 管理者が「小説投稿のCWフォールバック」を有効にしている場合(コントロールパネルのJUICE設定、既定は無効)、JUICE以外のサーバーでは「小説」と書かれたCW付きで表示されます。仕組みは[AI生成物フラグ](./ai-generated-flag.md)のCWフォールバックと同じで、両方に該当する投稿ではAI生成物の方が優先されます。
- JUICE以外のサーバーでは本文が通常のノートとして表示されるため、`［＃…］`や`[newpage]`などの記法は、そのまま文字として見えます。
