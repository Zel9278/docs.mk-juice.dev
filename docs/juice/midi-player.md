# MIDIプレイヤー

ノートに添付されたMIDIファイル(.mid/.midi)を再生できる、軽量な内蔵プレイヤーです。外部のサウンドフォントなどを使わず、Web Audio APIのオシレーター合成だけで動作します。

## 特徴

- GM(General MIDI)の音色ファミリーごとの合成レシピに対応しており、楽器ごとに異なる音色で再生されます。
- コントロールチェンジ・ピッチベンドにも対応しています。
- 128鍵の鍵盤ビジュアライザーで、どの音が鳴っているかをトラックごとに色分けして表示します。
- ピアノロールビジュアライザー(縦スクロール)も備えており、tick(拍の内部単位)基準で再生位置を表示するため、テンポ変化がある曲でもずれにくくなっています。有効/無効・ロール速度・最大同時発音数は、設定の「JUICE」ページとプレイヤー内のメニューのどちらからでも変更できます。
- 音量調整・シークバーを備えています。
- BPMと同時発音数(ノート再生数)をライブ表示します。
- AudioWorkletによるピークリミッターで、音割れを防ぎます。
- Media Session APIに対応しており、スマートフォンのロック画面や通知領域からも再生・一時停止などの操作ができます。

## 添付できるファイルサイズの上限

黒MIDIなど、ノートイベント数が極端に多いファイルを解析・再生するとブラウザがフリーズするおそれがあるため、再生を許可する最大ファイルサイズが設定されています(既定500KB)。上限は管理者がコントロールパネルのJUICE設定から変更できます。上限を超えるファイルは、プレイヤーではなく通常の添付ファイルとして扱われます。
