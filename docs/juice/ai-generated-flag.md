# AI生成物フラグ

投稿やDriveファイルが、AIによって生成されたものであることを示すフラグです。

## 使い方

ノート投稿画面で、AIで生成した画像・音声などを添付する際に「AI生成物」フラグを設定できます。設定すると、添付したDriveファイルにも自動的に連動します。

- フラグを立てたノートには「AI Generated(AI生成)」のバッジが表示されます。
- リノート時もフラグの表示は維持されます。
- 投稿後に、編集でフラグを変更することもできます。

**AI生成コンテンツを投稿する場合は、必ずこのフラグを設定してください。** 詳しくは[ルール](../service/rules.md)をご覧ください。

## 他サーバーとの連合

フラグの情報は、Juice Server独自のActivityPubプロパティとして連合先のサーバーにも送信されます。対応していないサーバーからは単に無視されます。

## ミュート設定

AI生成物付きの投稿をミュートする設定も利用できます。またDriveの「AI生成物のみ」フィルターで、AI生成物として登録したファイルだけを絞り込むこともできます。
