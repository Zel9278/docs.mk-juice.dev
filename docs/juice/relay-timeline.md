# リレータイムライン

登録されたリレーサーバー経由で届いたノートだけを表示する、専用のタイムラインです。

## 対象になる投稿

- リレー経由で届いた、公開範囲が「公開」のノートのみが対象です。フォロワー限定やダイレクトなどは対象外です。
- リレーが追加される前に届いていたノートは対象になりません。

## 利用方法

タイムライン切り替えから「リレー」を選択すると閲覧できます。他のタイムラインと同様、新着ノートがリアルタイムに表示されます。

各ノートには、どのリレー経由で届いたか(ホスト名)が表示されます。

## デッキでの利用

デッキUIの「タイムライン」カラムを追加・編集する際の種別選択からもリレータイムラインを選べます。カラムごとに絞り込むリレーを個別に設定できます。
