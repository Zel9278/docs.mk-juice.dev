# 小説エディター

[小説フラグ・小説ビューワー](./novel.md)向けの本文を書くためのエディターです。ナビゲーションのメニューから開けます(`/novel-editor`)。書き上げた本文は、そのまま.txtファイルにして小説フラグ付きで投稿できます。

## 作品と下書き

- 作品ごとに題名・本文・目標文字数を持ち、「作品」から切り替えたり、「新しい作品」を作ったりできます。
- 下書きは**このブラウザに自動で保存**されます。同じブラウザの別のタブとも同期します。
- 保存先はブラウザなので、別の端末やブラウザとは共有されません。ブラウザのデータを消すと下書きも消えるので、大事な作品は「.txtで保存」で手元にも残しておいてください。ブラウザの保存容量を超えて保存できなかった場合は、画面に知らせが出ます。

## 書く

本文の記法(ルビ・傍点などの注記、章タイトル、区切り、改ページ、太字など)には色が付き、見分けやすくなっています。次の記法は、ボタンから入力できます。

| ボタン | 入力されるもの |
| --- | --- |
| ルビ | 選んだ文字にルビを付けます(`[[rb:基底 > よみ]]`の形で入ります) |
| 傍点 | 選んだ文字に傍点(﹅)・白ゴマ傍点(﹆)・丸傍点(●)・白丸傍点(○)を付けます |
| 装飾 | 選んだ文字を太字・斜体・打ち消し線にします |
| 字下げ | 選んだ行を、指定した字数だけまとめて字下げします |
| 章タイトル | ここから始まる章の題名(`[chapter:…]`)を入れます |
| 区切り | ここで章を区切ります(`---`) |
| 改ページ | ここでページを変えます(`[newpage]`) |
| ダッシュ・三点リーダー | `――`・`……`を入力します |

書き方の詳しい意味は、[小説フラグ・小説ビューワー](./novel.md#本文で使える書き方)を参照してください。

### 表示と入力の設定

- 改行したら段落の頭を字下げする
- 括弧を自動で閉じる
- 書いている行を画面の真ん中に保つ
- プレビューを横に並べる
- 書体・文字サイズ・行の高さ

「集中モード」にすると、エディターを全画面で表示します。「検索・置換」では、大文字と小文字の区別・正規表現・単語単位での検索もできます。

## 目次と文字数

- 目次には章ごとの文字数が表示され、押すとその位置へ移動します。
- 文字数・原稿用紙換算(400字詰め、1行20字で段落ごとに改行した場合の枚数)・選択範囲の文字数が表示されます。文字数には、空白・改行・ルビのよみ・注記などの記法は含まれません。
- 「目標文字数」を決めておくと、進み具合が表示されます。

## プレビュー

小説ビューワーと同じ見た目でプレビューできます。広い画面ではエディターの横に並べて、狭い画面では別ウインドウで表示されます。書いている間も、そのままプレビューに反映されます。

## 投稿前のチェック

「投稿前のチェック」は、気になる箇所を一覧にして別ウインドウで表示します。項目を押すと、エディターのその行へ移動します。書いている間も結果は更新され、投稿するときにも気になる箇所があれば知らせます(「このまま投稿」で、そのまま投稿することもできます)。主に次のような箇所を指摘します。

- ルビの付け方(《》の前に漢字が無い、漢字以外を含む語に`｜`が無い、ルビの記法の書き間違い)
- 括弧の閉じ忘れや、対応する開き括弧の無い閉じ括弧
- 1行の中で閉じていない太字・打ち消し線・傍点の注記、閉じていない字下げの注記
- 小説ビューワーが対応していない注記(`［＃改ページ］`には対応していないので、`[newpage]`を使うよう案内します)
- それだけの行になっていない`[newpage]`、中身の無い章、1章目に`[chapter:…]`が無い場合
- 三点リーダー・ダッシュを1つだけ使っている、「・・・」を使っている、！？の後に全角スペースが無い

## 読み込み・保存・投稿

- **読み込む**: 端末またはドライブの.txtファイルを、新しい作品として開きます。文字コードは自動で判定します。
- **.txtで保存**: 本文を.txtファイルとして保存します。
- **投稿する**: 本文を.txtファイルにしてドライブへ上げ、小説フラグを付けて投稿フォームに添付します。
