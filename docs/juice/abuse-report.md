# 通報

ユーザー・ノート・チャットメッセージを通報する機能です。

## 通報方法

- ユーザーページの「…」メニューから「通報」を選ぶと、対象ユーザーへの通報フォームが開きます。
- ノートやチャットメッセージのメニューからも通報でき、その場合は対象のノート・メッセージが通報に自動で紐付けられます。
- 通報時にはカテゴリを選択できます(スパム・嫌がらせ・なりすましなど)。カテゴリはコントロールパネルのJUICE設定から追加・編集・並び替えできます。

## 対象コンテンツのプレビュー

ノートやチャットメッセージを通報した場合、モデレーター向けの通報詳細画面でその内容をプレビュー表示できます。チャットのダイレクトメッセージについては、通報を受けた場合に限りその内容を運営が確認できる、初めての経路です(通常、チャットの内容は管理画面から閲覧できません)。

## 管理側の対応

- コントロールパネルの通報一覧は、カテゴリで絞り込んで確認できます。
- 「ツール」メニューからの通報管理へのクイックアクセス・専用画面(`/abuses-manager`)があり、コントロールパネル全体を経由せずに通報の確認・対応ができます。

## ブロックしてから凍結

管理者・モデレーターがユーザーを凍結する際、対応した本人への報復的な絡み(メンション・フォローなど)を先に断てるよう、自分自身のアカウントで対象ユーザーをブロックしたうえで凍結できる機能があります。コントロールパネルのユーザー詳細画面・ユーザーメニューのどちらからも利用できます。
