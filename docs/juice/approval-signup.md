# 承認式新規登録

Juice Serverでは、新規登録の際に登録理由の入力を必須とし、管理者が内容を確認した上で承認する「承認式新規登録」を採用しています。誰でも即座に登録できるわけではありません。

## 登録の流れ

1. 新規登録画面で、メールアドレスなどの通常項目に加えて「登録理由」を入力します(最大4096文字)。
2. 登録完了後、アカウントは承認待ち状態になり、承認されるまではログインできません。
3. 管理者(モデレーターまたは管理者権限を持つユーザー)が登録理由を確認し、承認または却下します。
4. 承認されるとログインできるようになります。却下された場合は通知されます。

登録理由は一般ユーザーや他の申請者には公開されず、**管理者のみ**が確認できます。

## 審査状況の確認

承認待ちの間はログインできないため、専用の確認コードを使うことで審査状況(承認待ち・承認済み・却下)を確認できます。登録完了時に案内される確認コードは大切に保管してください。

このサーバーの承認式登録の背景については、[このサーバーの運用方針について](../about-juice-server.md)もご覧ください。
