# JUICE独自機能の設定

Juice Serverには、標準のMisskeyには無い独自機能がいくつかあります。これらの独自機能に関する設定は、コントロールパネルの「**JUICE**」項目にまとめられています。

## 設定できる主な項目

管理者アカウントでログインし、コントロールパネル → 「JUICE」から、以下のような独自機能の有効・無効や各種オプションを変更できます。

- [承認式新規登録](./approval-signup.md)の有効・無効、登録理由の必須/任意・最大文字数
- 作成から一定時間が経過していないアカウントからのフォローを、フォロー先の承認制フォロー設定に関わらず承認が必要なフォローリクエストとして扱う機能の有効・無効、しきい値
- [ユーザーランキング](./user-ranking.md)の集計期間・表示人数
- [リレータイムライン](./relay-timeline.md)の有効・無効
- [メディアタイムライン](./media-timeline.md)の有効・無効
- [絵文字申請](./emoji-request.md)・アバターデコレーション申請の有効・無効、同時申請数の上限
- [LaTeX(数式)表示](./latex.md)の有効・無効
- [お問い合わせフォーム](./contact-form.md)の有効・無効、カテゴリ管理、本文の最大文字数
- ウェルカムページ・「アカウントを追加」メニューの「招待コードで登録」ボタン、「他のサーバーを探す」ボタンの表示・非表示
- 起動時のロード画面に表示するカスタムスプラッシュテキスト

個人ごとの設定([ウィジェット表示位置](./widget-position.md)、タイムラインのタブバーに表示するタイムラインの選択など)は、こちらとは別に `/settings/juice` から変更します。

各機能の詳しい内容は、それぞれのページをご覧ください。
