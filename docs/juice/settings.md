# JUICE独自機能の設定

Juice Serverには、標準のMisskeyには無い独自機能がいくつかあります。これらの独自機能に関する設定は、コントロールパネルの**「JUICE」項目**にまとめられています。

## 設定できる主な項目

管理者アカウントでログインし、コントロールパネル → 「JUICE」から、以下のような独自機能の有効・無効や各種オプションを変更できます。

- [承認式新規登録](./approval-signup.md)の有効・無効、登録理由の必須/任意・最大文字数
- [ユーザーランキング](./user-ranking.md)の集計期間
- [リレータイムライン](./relay-timeline.md)の有効・無効
- [絵文字申請](./emoji-request.md)の有効・無効
- [LaTeX(数式)表示](./latex.md)の有効・無効

個人ごとの設定([ウィジェット表示位置](./widget-position.md)など)は、こちらとは別に `/settings/juice` から変更します。

各機能の詳しい内容は、それぞれのページをご覧ください。
