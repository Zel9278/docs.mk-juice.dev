# アバターデコレーション申請

一般ユーザーがアバターデコレーションの追加を申請できる機能です。仕組みは[絵文字申請](./emoji-request.md)と同様です。

## 申請方法

アバターデコレーション申請ページから、以下の項目を入力して申請します。

- デコレーション画像
- 名前
- 説明
- カテゴリ

申請は却下または承認されるまで保持されます。承認されると、そのままアバターデコレーションとして利用できるようになります。却下された場合は理由が通知されます。もう一度申請したい場合は、新しい申請として出し直してください。

## 申請前に準備しておくと良い項目

以下のような内容をあらかじめ用意しておくと、フォームへの入力がスムーズです。

```
デコレーション名:
説明:
カテゴリ:
```

## 申請数の上限

同時に出せる申請(審査待ち)の件数には上限があります(既定3件)。また、連続申請を防ぐためのレート制限もあります。

## 申請画像の扱い

申請時に、審査完了後に画像を削除するかどうかを選択できます。チェックを入れた場合、承認・却下いずれの場合も審査完了時にDriveファイルが削除されます(承認時はデコレーション側に画像がコピーされるため、削除しても本体には影響ありません)。
