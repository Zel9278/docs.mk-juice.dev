# LaTeX(数式)表示

ノート内でLaTeX形式の数式を書くと、実際にレンダリングされて表示される機能です。本家Misskeyが過去に持っていた機能を、Juice Serverで復旧したものです。

## 書き方

MFMの数式記法を使います。

- インライン数式: `\(` と `\)` で囲む
- ブロック数式: `\[` と `\]` で囲む

## 注意

- 数式の内容によっては表示に失敗することがありますが、その場合もページが壊れることはなく、その部分だけ表示されません。
- この機能はサーバー全体の設定で無効化されることがあります。無効時は数式のソースがそのままコードとして表示されます。
