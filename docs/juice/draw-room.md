# 絵チャ

部屋を作って、複数人で同じキャンバスに絵を描ける機能です(お絵かきチャット)。ナビゲーションのメニュー、または「ゲーム」ページから開けます(`/draw`)。

## 部屋を作る

「部屋を作る」から、部屋主が次の項目を決めます。

- **部屋の名前**
- **公開範囲**: 「フォロワーのみ」または「ローカル全体」
- **描ける人数の上限**: 2〜512人。あとから変更できます。上限を超えた人も、見学者として部屋に入れます
- **キャンバスの大きさ**: 横長(1600×900)・縦長(900×1600)・正方形(1200×1200)・正方形・大(2048×2048)・正方形・特大(3840×3840)のプリセットか、幅・高さを100〜3840の範囲で自由に指定します。あとから変更することもでき、その場合は左上を基準に広げたり切り詰めたりします。小さくしてはみ出した線は消えずに残るので、大きくし直すとまた見えます
- **終了後もサーバーに保存する**: オフにすると、部屋を終了してから1時間後に絵とチャットが削除されます

ロールによっては部屋を作れない場合があります。その場合でも、ほかの人の部屋には参加できます。

## 参加と見学

- 開催中の部屋は、絵チャのページの一覧に表示されます。部屋に入ると、まず見学者として開きます。
- 「描く人として参加」を押すと描けるようになります。満員の場合は見学のみになります。
- 見学者もチャットには書き込めます(1回500文字まで)。絵文字・カスタム絵文字も使え、発言には時刻が表示されます。
- 部屋を開いている人(オンライン)は一覧に表示されます。部屋を閉じたり、別のタブへ移ったりした人はオフラインになります。
- 部屋主は、描いている人を「描く人から外す」ことができます(外された人は見学者として残ります)。
- 部屋主も「観戦モードにする」で描く人から抜けて見学できます。部屋主のままなので、満員でも描く人に戻れます。

## 描く

- **ペン**: ペンタブレットなどの筆圧に対応しています。筆は「普通の筆」「にじみ筆」「ドット(くっきり)」から選べます。
- **消しゴム**: 太さはペンとは別に設定できます。
- **囲って塗る**: 囲んだ範囲を塗りつぶします。
- **塗りつぶし(バケツ)**: 押した所の、線で囲まれた範囲を塗りつぶします。
- **線の中だけ塗る**: 描き始めた所を囲む線の中にだけ塗れるようにします。
- **スポイト**: キャンバスから色を拾います。キーボードの`I`、またはAltキーを押しながらクリックでも使えます。
- **色・太さ・濃さ(不透明度)**: 太さの上限は、キャンバスの大きさに合わせて変わります。
- **元に戻す**: `Ctrl+Z`でも取り消せます。
- **自分のレイヤーを消去**: 自分が描いた線をすべて消します。

### 選択と移動

- **範囲選択・投げ縄選択**: 自分の線を選びます。選んだ範囲の境目で線が切れるので、線の一部だけを選べます。Shiftキーを押しながら選ぶと、選択に追加できます。
- **移動**: 選んだ線を動かします。何も選んでいなければ、自分のレイヤー全体を動かします。
- 選んだ線は、左右に回転したり、削除(`Delete`・`Backspace`)したりできます。`Esc`で選択を解除します。

線は描いた人ごとのレイヤーに分かれているので、他人の線を消してしまうことはありません。レイヤーごとの表示/非表示と、自分のレイヤーを一番上に表示する切り替えができます。部屋主は、ほかの人のレイヤーを「このレイヤーを消去」で消すこともできます。1人のレイヤーに描ける線の量には上限があり、超えた操作はサーバーで受け付けられずに元に戻ります。

ほかの人のカーソルは、その人のアイコン付きの丸で表示されます。

## 表示の操作

- **拡大縮小**: マウスホイール、拡大・縮小ボタン、`Ctrl+＋`/`Ctrl+－`、またはタッチ操作で2本指のピンチ。拡大は最大3200%です。「ホイールで拡大縮小」をオフにすると、ホイールは表示の移動になり、拡大縮小は`Ctrl`+ホイールになります(この設定はブラウザに保存されます)
- **移動**: `Shift`+ホイール、マウスの中ボタンでドラッグ、スペースキーを押しながらドラッグ、手のひらツール(`H`)、またはタッチ操作で2本指のスライド。手のひらツールは線を動かさず、表示だけを動かします
- **回転**: 左右に回転するボタン、またはスマートフォンなどでは2本指でキャンバスを回転できます。「回転を戻す」で元に戻ります
- **ピクセルアート拡大モード**: 拡大してもぼかさず、画素をそのまま大きく表示します(全体マップにも反映)。このモードで800%以上に拡大すると、画素の格子も表示されます
- **全体マップ**: 今見ている範囲をキャンバス全体の中で示します。表示/非表示を切り替えられます
- **画面に合わせる**: キャンバス全体が収まる倍率に戻します(`Ctrl+0`)

スマートフォンや狭いウインドウ(デッキを含む)では、キャンバスを広く取り、レイヤーとチャットは下から引き出すパネルで表示されます。ボタンには名前が表示され、ページのヘッダーのボタンは名前付きのメニューにまとめられます。

## 画像として保存・投稿する

開催中・終了後のどちらでも、キャンバス全体、またはドラッグで囲んだ範囲を画像にできます。

- 画像をドライブに保存
- 画像をノートに投稿
- 画像をダウンロード

保存形式は、PNG(無圧縮)・WebP(Misskeyのアップロード時と同じ圧縮)・JPEGから選べます。

## 部屋の終了

- 部屋主は「絵チャを終了」で部屋を終了できます。終了すると誰も描けなくなります。
- 「終了後もサーバーに保存する」がオンの部屋は、終了後も閲覧のみで残り、「保存した絵チャ」から見られます。オフの部屋は、終了から1時間後に削除されます。残したい場合は、それまでに画像を保存・投稿してください。
- 24時間なにも描かれず、発言もされなかった開催中の部屋は、自動で終了します。

## 通報とモデレーション

- 部屋のメニューの「部屋を通報」から部屋そのもの(部屋主)を、チャットの発言からその発言(発言した人)を[通報](./abuse-report.md)できます。通報した時点の内容が残り、管理画面の通報に表示されます。
- モデレーターは、問題のある部屋を開催中でも削除できます。削除はモデレーションログに記録されます。モデレーターとして部屋を確認している間、そのことは部屋の人には表示されません。

## 管理者向けの設定

- コントロールパネルのJUICE設定で、絵チャそのものを有効/無効にできます(既定は有効)。無効にすると、部屋を作ることも入ることもできなくなり、メニューからも消えます。
- ロールポリシーで、次の項目をロールごとに設定できます。
  - **絵チャの部屋の作成**: オフにしても、ほかの人の部屋の見学・参加はできます(既定はオン)
  - **絵チャで作れるキャンバスの大きさの上限**: 幅・高さそれぞれの上限(100〜3840、既定は3840)。部屋を作るときと、途中で大きさを変えるときに適用されます
