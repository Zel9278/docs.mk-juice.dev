# 更新履歴

misskey-juiceのJUICE独自機能に関する主な変更履歴です。本家Misskey由来の変更は含みません。全履歴は[GitHubのリリースページ](https://github.com/Zel9278/misskey-juice/releases)をご覧ください。

## v2026.9.0-juice+3.4

- [メディアタイムライン](./media-timeline.md)を追加。添付ファイル付きの投稿だけをグリッド/カルーセル表示で集める、PixelFed風の専用タイムラインです(管理者が有効化した場合のみ利用可能)。動画・音声ともその場でインライン再生でき、投稿ごとに表示を除外することもできます
- ライトボックス・メディアタイムラインのインライン再生全体で音量設定を共有するように変更(端末ローカルに保存)
- タイムラインのタブバーに表示するタイムラインを、閲覧者ごとに`/settings/juice`から個別に非表示にできるように

## v2026.9.0-juice+3.3

- 絵文字申請・承認式登録申請などの未対応バナーが、対応済みになってもコントロールパネルを開いている間は消えなかった問題を修正
- スマートフォンでのナビゲーションバー・絵文字パレット・ウィジェットの並べ替えが、タッチ操作(特に長押し)で正しく動作しなかった問題を修正
- 新規登録後のプロフィールセットアップで、横長など縦方向が狭い画面においてアイコン変更・保存ボタンなどがフッターの「戻る/続ける」ボタンと重なって表示される問題を修正

## v2026.9.0-juice+3.2

- 絵文字申請・アバターデコレーション申請の新着通知・承認式新規登録の申請・お問い合わせの新着通知を、通常の通知(🔔の通知一覧)にも残るように変更。モデレーター以外のロールポリシー保持者にもアプリ全体で常時リアルタイム通知が届くように
- [絵文字申請](./emoji-request.md)・アバターデコレーション申請を、審査待ちの間であれば申請者自身がキャンセルできるように
- ウェルカムページ・「アカウントを追加」メニューの「招待コードで登録」ボタン、「他のサーバーを探す」ボタンをそれぞれ管理者設定で非表示にできるように
- 標準テーマにJUICEブランドカラーのオレンジを基調にした「Juice Orange」(ライト/ダーク)を追加し、標準の初期テーマとして設定
- [リレータイムライン](./relay-timeline.md)に、各ノートがどのリレー経由で届いたかを表示するように
- [表示言語のフィルター](./post-language.md#タイムラインの言語フィルター)が一部のタイムライン・リアルタイムストリーミングに効いていなかった問題を修正。あわせて、言語が指定されていない投稿の扱いと、自分の投稿を常に表示するかどうかの設定を見直し
- 「削除して編集」フォームの誤操作防止(閉じる前の確認ダイアログ)と、内容が消えてしまう不具合を修正
- リアクション相乗りでリモート絵文字を使った場合に、本家Misskey等でハートへフォールバックしてしまう問題を修正
- 英語・韓国語・簡体字中国語の翻訳をJUICE独自項目に追加

## v2026.9.0-juice+3.1

- [絵文字の情報メニュー](./reaction-enhancements.md#絵文字の情報メニュー)を、リアクションだけでなくノート本文・CW・プロフィールなどに埋め込まれた絵文字でも利用できるように
- [お知らせのリアクション機能](./announcement-reaction.md)で、付けられるリアクションの種類数の上限をロールポリシーで設定可能に(既定20種類)
- 相乗りリアクションでリモート絵文字を使う際の著作権に関する注意書きを、管理画面とアプリ内の[About JUICEページ](./about-page.md)にも追加
- お気に入りデッキカラムの表示・リアルタイム反映に関する不具合を修正
- ジョブキューウィジェットの通知音設定を、有効/無効の切り替えと音の選択を分ける形に変更

## v2026.9.0-juice+3.0

本家Misskey 2026.9.0への追従にあわせた大型リリースです。主な追加機能:

- [リアクション機能の拡張](./reaction-enhancements.md)(相乗りリアクション、リモート絵文字リアクションの解決、リアクション検索タブなど)
- [投稿言語](./post-language.md)
- [ノート検索の強化](./note-search-enhancements.md)
- [お問い合わせフォーム](./contact-form.md)
- 絵文字・アバターデコレーション申請に、複数枚まとめての申請・差し替え申請・承認時の内容編集機能を追加
- [ユーザーランキング](./user-ranking.md)の表示人数をJUICE設定から変更可能に(既定3人)
- モデレーション・管理者向け通知を拡充(絵文字申請・お問い合わせ等の新着をコントロールパネルにリアルタイム表示)
- システムメールの多言語対応
- 各種セキュリティ強化(captcha適用範囲の拡大、ログイン失敗の本人通知、審査処理の排他制御など)
- デッキUIのカラムに「お気に入り」を追加
- 起動時のロード画面に起動ログ表示と、カスタムスプラッシュテキスト設定を追加
- ジョブキューウィジェットの通知音を好きなサウンドに変更可能に
