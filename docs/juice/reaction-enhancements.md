# リアクション機能の拡張

標準のMisskeyのリアクション機能に対する、いくつかの拡張機能です。

## 相乗りリアクション

ノートに既についている他のユーザーのリアクションをクリックすると、自分も同じリアクションを付けられます。ロール制限・センシティブ・ローカル限定といった、通常のリアクション時と同じ権限チェックが適用されます。

リモートサーバーのカスタム絵文字によるリアクションへの相乗りは、他インスタンスの絵文字画像を著作権者の許諾なく使用することになりうるため、コントロールパネルのJUICE設定でオプトイン(既定は無効)になっています。

::: warning 注意
相乗りリアクションでリモートインスタンスの絵文字を使用すると、その絵文字画像を著作権者の許諾を得ないまま利用することになる可能性があります。ライセンス上の判断は、利用するユーザーご自身の自己責任でお願いします。

Juice Serverでは、この機能の動作検証を目的として、現在テストのために有効化しています。
:::

## リモートカスタム絵文字リアクションの解決

リアクション文字列(`:name@host:`)でリモートホストのカスタム絵文字を指定した場合、ローカルユーザーからのリアクションに限り、指定ホスト→ローカル→ノート投稿者のホストの順で絵文字を探して認識します。

リモートから受信したリアクションについては、なりすまし防止のため従来通りリアクションした本人のホストのみが対象です。この機能をJUICE設定で無効化した場合も、本人のホスト(ローカル)の絵文字のみを対象にする従来の挙動になります。

## 絵文字の情報メニュー

絵文字をクリックすると表示される「情報」メニュー(ライセンスなどの詳細情報や、絵文字の提供元ホストを確認できます)が、ローカルのカスタム絵文字だけでなく、リモートサーバーのカスタム絵文字でも利用できます。リアクションに限らず、ノート本文・CW・プロフィールなどに埋め込まれた絵文字でも同様です。

## リアクション検索

検索ページに、自分が付けたリアクションでノートを絞り込む専用タブ「リアクション」があります。

- 「何かしらリアクションした投稿」、または特定のリアクションを選んでの絞り込みができます。
- ノート検索と同じ高度な検索オプション・日時範囲・検索範囲・URL/@ユーザー/#タグの自動リンクも組み合わせられます。
- プライバシー上、対象は自分自身のリアクションのみです。
