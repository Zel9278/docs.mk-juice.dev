# このインスタンスの運用方針について

## Juice Serverとは

Juice Serverは、Misskeyの非公式フォークである[misskey-juice](https://github.com/Zel9278/misskey-juice)の[`juice/main`ブランチ](https://github.com/Zel9278/misskey-juice/tree/juice/main)を追従している公式インスタンスです。

## テストインスタンスとしての位置づけ

Juice Serverは、misskey-juiceで開発した新機能や修正を実際の運用環境で検証するために構築・運用しています。

- **承認式新規登録は、この検証目的のために現在有効にしています。** 誰でも自由に登録できるインスタンスではなく、登録申請の内容を確認した上で承認する形式です。
- misskey-juiceの検証中の機能を先行して有効にしていることがあり、想定外の不具合が発生する可能性があります。
- 不具合を発見した場合は、Misskeyのメッセージで管理者（[@c30](https://mk-juice.dev/@c30)）までご連絡いただけると助かります。

## 汎用インスタンスとしての運用

上記のテスト目的に加えて、**創作活動をする方や、他の人と普通に交流したい方向けの汎用インスタンスとしても運用していく予定です。**

ご利用の際は、必ず以下をお読みください。

- [ルール](./service/rules.md)
- [利用規約](./service/tos.md)

## データの取り扱いについて

- データベースは定期的に自動バックアップを取得し、暗号化した上で外部ストレージに保管しています。
- ただし、テストインスタンスという性質上、検証中の不具合などによりデータが失われる可能性はゼロではありません。あらかじめご了承ください。

## お問い合わせ

ご質問・ご要望・不具合報告は、Misskeyのメッセージで管理者（[@c30](https://mk-juice.dev/@c30)）までご連絡ください。
