# カスタム絵文字・アバターデコレーションのガイドライン

カスタム絵文字やアバターデコレーションを申請する際は、以下のガイドラインを守ってください。[ルール](./rules.md)・[利用規約](./tos.md)とあわせてご確認ください。

## 共通の注意事項

- ライセンス表記が必要な素材(クレジット表記必須のフリー素材など)を使う場合は、「ライセンス」欄に出典・作者名・ライセンスの種類を正確に記載してください。自作のものや、ライセンス表記が不要な素材であれば、無理に記載しなくても大丈夫です。
- 実在の企業・団体のロゴや商標を無断で使用する申請は却下します。ただし、そのロゴ画像に利用を認めるライセンスが明記されている場合(公式に素材として配布されているものなど)は、企業の公式URLと画像のライセンスを「ライセンス」欄に記載していただければ問題ありません。
- NSFW・暴力的・差別的な内容を含む画像は申請できません。[ルール](./rules.md)の基準に準じます。
- 公序良俗に反する表現の再現など、想定される用途外での申請も却下対象です。
- 判断に迷う場合は、審査の際に個別に確認することがあります。あまり硬く考えず、気軽に申請してください。

## カスタム絵文字

- 名前・カテゴリは分かりやすく、他の絵文字と混同しにくいものにしてください。
- 申請は承認または却下されるまで保持されます。却下された場合は理由が通知されます。もう一度申請したい場合は、新しい申請として出し直してください。
- 詳しい申請方法は[絵文字申請](../juice/emoji-request.md)をご覧ください。

### 他のインスタンスの絵文字を持ってくる場合

Misskeyには、他のインスタンスで使われている絵文字をダウンロードして自分のインスタンスに取り込む文化があります。当インスタンスでも、他のインスタンスの絵文字をそのまま使いたい場合に申請していただいて構いません。

- 取得元でライセンスが明記されている場合は、それに従って「ライセンス」欄に記載してください。
- 取得元にもライセンス情報が特に無い(何も書かれていない)場合は、「ライセンス」欄に取得元のインスタンス名を書いていただければ十分です。厳密なライセンスが分からないからといって申請を諦める必要はありません。
- 元の絵文字の作者が「無断転載・再配布しないでほしい」のように明言している場合や、実在の企業ロゴ・商標など明らかに問題がある絵文字は申請しないでください。

## アバターデコレーション

- カスタム絵文字と同じ申請の仕組みで、画像・名前・カテゴリ・ライセンスを入力して申請します。
- プロフィールアイコンに重ねて表示されるものなので、透過背景の画像など、アイコンに重ねることを前提としたデザインにしてください。

## 承認について

申請の承認・却下は、管理者またはロールで承認権限を委譲されたユーザーが行います。上記のガイドラインに沿わない申請は却下されることがあります。
